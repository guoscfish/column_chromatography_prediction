# LLM引导模型诊断的有限研究路线

**本轮没有实现自动改模型Agent，没有新的LLM请求，也没有启动本路线的任何拟合。** 当前15次Original/Loading-Amount Skip/Sample-Volume Skip训练由本任务训练主模块统一执行；本文件不扩展其模型、seed、epoch、数据或预算。

最值得检验的是：LLM能否从真实反馈中提出一个可被数值诊断证实、并能改善未参与选择的Row预测的具体机制假设。把现有三个预定义模型全部训练一遍，再让LLM选择最低损失者，不能证明LLM提供了人或普通搜索之外的知识。

## 严格分层的研究闭环

| 层级 | 允许的输入 | 必须先冻结的输出 | 拒绝条件 |
|---|---|---|---|
| 科学假设 | 当时已揭示训练反馈、分子与条件、预测响应；无test或未揭示候选真值 | 因素、方向、适用分子/条件、人群边界、可证伪预测 | 仅说“试更多网络/层数”、没有数值预测 |
| 诊断 | 冻结checkpoint/缓存与同条件系列 | 同模型状态的幅度、方向、平坦率、信息路径和反例 | 跨checkpoint拼接差分、事后挑最好/最差例 |
| 数值资格 | 已授权观察数据与预定义阈值 | 解释被支持或反证的条件，缺失/不可识别因素 | 用近零真值作分母、把相关性当唯一机制 |
| 有限模型提案 | 通过资格的诊断摘要 | 修改目录中的一个条目、预期B−A/C−B结果与失败标准 | 自由生成架构、同时改loss/网络/采集/Prompt |
| 固定标签训练 | 预定完整系列隔离、相同初始化与训练RNG | 代码/配置/hash/训练预算、所有seed | 检查集选checkpoint、增加有利seed或偷偷调参 |
| 接受或拒绝 | 预定局部与Row指标，全部模型均报告 | 工程门槛及外部确认需求 | 只报局部改善或best-so-far，不报Row恶化 |

本轮有限模型集合已经固定为A原模型、B归一化loading amount直接残差、C独立样品体积同规模直接残差；B/C零初始化、每端点三个分位共享偏移、保留原非负约束。未来若该路线未达到门槛，应停止简单skip路径，不自动扩大为更多激活函数、损失组合或LLM架构搜索。

## LLM知识贡献应怎样被识别

未来并列保留三个基线，预算、可见资料和有限修改目录完全一致：

1. **确定性诊断规则**：根据同批样品体积响应压缩、已有loading amount可辨识性及预定义规则选择一个修改；不使用语言模型。
2. **人提出的假设**：研究者在不看候选模型validation结果前写下机制、修改与失败标准；记录时间和信息范围。
3. **普通有限搜索**：在相同A/B/C目录与相同拟合预算内枚举或按预定规则评估；不能为LLM额外提供更多候选与试错轮次。

LLM也只能先提交冻结假设和一个目录项。知识价值的证据应是提前预测了哪些条件/分子会改善、哪些不会，并在独立确认中优于相同信息的规则/人基线；不能仅以“最后挑中了好模型”作为证据。若LLM仅复述已给出的压缩结论或选择人已预定义的C，即使C有效，也只支持该表示干预，不支持LLM发现能力。

可以把假设文本匿名、去除模型名称后给人盲审其可检验性；本轮不执行外部Judge，不以另一个LLM的赞同代替实验。最终裁决仍是预定数值与Row预测。

## 防止反复查看validation造成适应性过拟合

- 先冻结假设、模型目录、初始化、seed、训练数据/系列分组、指标和停止条件。每个提案只给一个不可变版本号，不在失败后换措辞重新算新假设。
- LLM只看授权训练诊断摘要，不看逐模型validation曲线、候选排行榜或隔离体积检查集的真值/逐行误差。已有Row validation只按原冻结规则用于early stopping和checkpoint选择，由确定性训练控制器处理，不变成LLM反复提案的交互反馈。
- 隔离体积系列不参与early stopping、模型挑选或超参数搜索；完整系列及等价行整体隔离。先按seed算配对效果，再汇总，不能把实验对当独立科研重复。
- 当前历史validation已经多次用于开发，不能再声称它是未触碰的确认集。任何“LLM模型发现优于人/规则”的强确认都需要未来单独预注册的新确认人群或真正封存、未参与任何提案的外层集合；标签权限与额外训练另行授权，本轮不打开test truth或新标签。
- 保留所有失败提案、检查次数和累计预算。将20%局部差分MAE改善、至少4/5 seed同向、Row不明显恶化作为阶段门槛，不能解释为显著性定理；Row恶化的容忍量应在解封结果前固定。

## 保持模型与选点归因清楚

先在完全固定标签集合上比较A/B/C，LLM不参与新候选选择。局部条件改善而Row不变，只能支持局部表达路径，不足以解释主动学习效率差距。局部与Row均改善，才进入新的独立确认，仍不能认定LLM选点优于LCMD。

未来如需研究选点，另做冻结H/U/checkpoint的选择实验：预先固定同一候选预算与同一模型，对LLM、LCMD或局部修复方案分别取样；之后才在有明确授权的相同标签可见性下比较单步学习。不要在同一分支同时改模型、采集函数和Prompt。若必须同时研究两层，应完整交叉模型版本×选点策略，并将两层主效应与交互分别报告；该实验不是本轮15次拟合的自动追加项目。

## 失败后怎样停止

| 预定结果 | 可支持的结论 | 明确停止/下一步 |
|---|---|---|
| B/C都不改善局部检查 | 简单直接残差不足以解决当前压缩 | 停止skip路线，不继续搜索到正例 |
| B改善，C没有额外收益 | 强化已有loading amount路径值得确认 | 不声称必须新增独立体积输入 |
| C相对B也稳定改善 | 独立体积表达是待确认机制 | 独立数据确认信息贡献，不推断物理因果 |
| 局部改善，Row无改善 | 改善限于局部响应 | 放弃用该机制解释整体AL差距 |
| 局部与Row均改善 | 模型表示路径的工程干预有信号 | 独立确认；LLM贡献仍须对照规则/人 |
| LLM不优于同预算规则/人 | 尚无增量知识贡献证据 | 停止LLM模型发现扩张，保留确定性诊断 |

工程纠错保真与模型学习能力是独立问题：前者保护原提案并减少无关漂移，后者检验表示能否利用已购买的信息。局部修复保留了更多合法ID，不自动意味着这些ID对学习更有价值；模型响应改善也不自动证明LLM提出了更好的科学实验。
