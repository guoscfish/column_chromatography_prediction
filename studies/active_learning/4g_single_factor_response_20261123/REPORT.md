# 4g 单因素响应：模型能预测位置，不一定能预测位置如何改变

**核心结论。** 对常见的 EA 变化，真实响应有非常清楚的方向，而且同一分子内通常可以做非线性插值；它不是“一条直线”或每个分子共享同一斜率。样品上样量主要改变洗脱窗口形状，结果并不等于预测窗口整体后移。冻结模型对这两个方向的学习能力明显不对称。局部响应不足是改进模型的理由，但它还不能解释主动学习排序的因果机制。

## 一、实测最重要的五个发现

下表及正文比例先在每个分子内平均，再等权平均分子；配对总数只是覆盖量。结果来自质量一致的固定非 test 队列。变化均为高数值水平减低水平，类别除外。

| 因素 | 序列 / 相邻配对 / 分子 | V1 / V2 主要结果 | 解释边界 |
|---|---:|---|---|
| EA 份额 | 710 / 2,992 / 217 | 89.8% / 86.3% 下降，平均绝对变化 3.42 / 7.15 mL | 方向强于统一幅度；W 下降 80.7%，并非纯平移 |
| 样品上样体积 | 1,284 / 2,095 / 195 | V1 下降 76.0%，V2 上升 63.8%；W 增加 84.9% | C 上升 47.8%，无统一平移方向；负载展宽只是候选机制 |
| 流速 | 223 / 237 / 32 | V1/V2 上升 74.5% / 63.4%，平均绝对变化 1.28 / 2.57 mL | V 本身含流速×时间；体积单位的描述关系不证明改变流速导致该幅度 |
| 加载溶剂体积 | 11 / 11 / 1 | W 11/11 增大，平均绝对变化 12.91 mL | 只有一个分子，不能外推或当成 11 个分子 |
| 加载溶剂类型 | 21 / 21 / 2 | 存在毫升级类别差异 | 只有两个分子；类型差分为确定方向的类别比较，不是连续斜率 |

对正相硅胶，增加 EA 通常增强洗脱，强加载溶剂或较高负载可能改变峰宽。这与观察相容，但实验为现有条件轨迹，不隔离饱和吸附、样品带扩散、t1/t2 标注、装柱、批次与其它未记录过程。可参阅 Biotage 的 *Successful Flash Chromatography* 和其 5g 加载溶剂实验，作为机制背景而非本项目的验证。

## 二、平滑性、分子差异与噪声

- **非线性且局部可插值：** 在 210 个有至少四水平的 EA 分子上，每次只留一个内部水平，等权分子误差 V1/V2：全段直线 **3.18/6.67 mL**，局部分段直线 **2.07/4.31**，单调 isotonic **2.06/4.33**，平滑保形 PCHIP **1.35/2.81**。重用中点做训练内直线估计得到 **2.41/5.07**，不可和独立留中点口径混写。留中点是对已观测曲线的插值检查，不是未见分子或域外泛化。没有四水平上样量系列可做同样比较；三个水平的有符号形状仍可检查。
- **不是处处单调：** EA 局部三点中位偏离中点弦 **0.44/1.49 mL**，原始相邻斜率变号比例约 **20%/24%**；上样体积对应 **0.55/0.49 mL** 与 **37%/50%**。变号未去噪，小变化可由噪声造成；整序列 0.1 mL 容忍单调性另见 `physical_shape`。
- **分子不同、条件不均匀：** 按 TPSA ≤20、20–40、>40 Å²，EA 的 V2 平均绝对差为 **3.93、9.20、13.03 mL**（109、74、34 个分子）；上样展宽同三组为 **1.54、2.20、2.42 mL**（93、68、34）。这只是组内给定实验网格下的绝对差，不能解释成极性本身的因果效应；条件区间、结构类、原本保留量都可能不同。另附结构类/固定加载溶剂分层和 EA×样品量同区间的差上差。
- **重复变异不可忽略：** 可见严格同条件 25 个重复组、50 行，V1/V2 组内范围中位数 0.93/1.12 mL，90 分位 2.74/7.30 mL。它与部分小步上样差同量级，且范围受选点与批次影响，不是统一实验噪声或仪器分辨率。大的反趋势点按预先明确方向列出，优先核查时间起止、装柱/批次和手工端点，不能在没核查前把它删成离群点。
- **交互值得进一步确认：** 对同分子的相同 EA 区间，在不同样品量上配成四角，192 个分子的 V1/V2 差上差的分子等权平均绝对值 **1.22/1.93 mL**。与加载-洗脱相互影响相容，但统计为绝对值，会把重复变异也算入，不能当成因果交互幅度，不做全局交互检验。

## 三、模型和科研决策

正式 qualification row seed 42 在 EA 上的两端明确同向率 80.9%/89.2%；在上样量上只复现 6.5%/8.5% 的真实平均绝对变化幅度。五 seed 的固定配对验证显示：New Free32 全局 NRMSE 从 0.751 降到 0.379，早期上样近乎全平，L1005 V1/V2 仍有 57.6%/67.6% 的明显真实变化被预测近乎不变。较强恢复集中在两个 seed；上样 V2 比 V1 更弱。流速零响应源自未输入而非训练不足。冻结已接受反馈另独立复现了原来的 165 对。

详见 [冻结模型结果](MODEL_RESPONSE.md)、[AL 机制与限制](AL_IMPLICATIONS.md)、[下一阶段预案](NEXT_STAGE_DECISION.md)。先做配对差分损失的严格对照，不重复已经失败的线性旁路；最小设计需 10 次拟合，但本轮仅分析和推理。预测导向策略可以接着做，前提是证明 surrogate 的局部信息真的服务于固定目标域。
