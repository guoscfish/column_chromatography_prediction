# 对主动学习的含义

1. **LCMD 好不等于数据线性。** 历史五 seed 的 raw gradient-LCMD 在 L333–1005 AULC 为 0.46255（L1005 NRMSE 0.36633）；L333–1485 的 AULC 0.41705，优于 New CW-Free 的 0.45420，但 L1485 单点反过来是 New CW-Free 0.32270、raw LCMD 0.34758。不要把梯度空间 raw LCMD、CW-gradient LCMD、数值 Hybrid 合并为一个方法。非线性但可局部插值的主洗脱方向、分子/条件覆盖，以及 Row 验证的边际权重，都与覆盖作为高效基线**相容**；它们未被证明是 AULC 差异的原因。
2. **输入有差异、表示有距离、函数有响应，是三个不同命题。** Raw 条件向量仍可把上样量分开；它本身不需要模型敏感。Latent 覆盖使用学得的分子/条件表示；如果其距离主要由分子或 EA 驱动，上样差异可以被淹没。Gradient LCMD 使用输出对参数的梯度几何，并非对 `V/ul` 的物理导数：局部平坦提示某些信号可能弱，但不能推出梯度向量一定相同。历史 surrogate IVR 则由所选表示、核及联合后验决定，某个轴的低敏感只是风险之一。
3. **存在竞争解释。** 历史中期 AULC 差、选取批组成与位置、payload/重试导致的设计保真损失、优化波动、固定 Row 评价、以及 joint-surrogate 校准都可能起作用。历史报告已发现 New CW 的批内对照名额较多，单个历史量匹配却不专属于它；同策略里的简单覆盖量与下一批 gain 关联并不稳定。本轮不从相关性定因果，不用未测真值或局部响应差分 MAE 当在线 acquisition score。
4. **预测导向方法不是禁区，但需要独立门槛。** Fisher/BAIT 关注相对于目标分布的预期参数信息，EPIG 关注候选结果与目标域预测的后验依赖；二者都要求目标分布、敏感度/概率 surrogate 至少能捕获有价值的轴。EPIG v2 对同 surrogate 的配对 IVR 在既有有限预算探索中 AULC 差约 −0.01527，这是可以跟进的独立信号，不是它已胜过 LCMD、也不证明换模型后 BAIT/EPIG 一定获益。历史 IVR 也显示优化 surrogate 自己的指标不能推断真实学习收益。

给导师的判断：先检验真实局部曲线、再问模型学到多少，是正确的诊断顺序；把覆盖优势解释成统一线性，则与留中点误差、端点不同步和曲率证据冲突。短期保留 LCMD、Random 等匹配基线。需要额外区分：科学对照能增加可解释性，并不自动改善全局 Row NRMSE。
