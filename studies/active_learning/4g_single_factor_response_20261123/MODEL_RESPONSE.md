# QGeoGNN 学到了什么：三个不混合的证据层

**判断：** EA 方向和大量 EA 非线性已学到；`V/ul` 是有充分样本支持的已编码方向里最严重的短板。早期主要是近似不动，不是大量有强响应但方向相反。流速是另一个机制：它没作为独立输入，严格流速对预测不变是结构性限制，不应把这个零与上样量压缩混为一谈。

## 输入、标签和读取边界

- QGeoGNN V2 复用 canonical SMILES 构图、分子描述符和 6 个以配比加权的洗脱剂分子描述符；typed completion 分支处理加载溶剂类别、`密度×样品体积`（mg）、加载溶剂体积，有 checkpoint 对应的数值变换。网络按分子 sum pool 与 condition residual 相加，再进六输出 head；按 V1、V2 各取 q50。没有流速输入、没有独立样品 `V/ul` 或密度输入；纯度/CAS 用于匹配审计，非网络控制输入。
- 输出本身是 mL；固定目标尺度用于 combined NRMSE，并非把冻结预测再次乘回体积尺度。qualification 损失为 q10/q90 pinball、q50 平方误差及交叉惩罚，两端同权；不含明确的单因素配对监督。加载器校验输入 schema/hash、归一化约定、输出顺序、权重严格一致；冻结时验证选 checkpoint，不在本研究上挑模型或阈值。
- 三种范围不合池：① qualification row 与 compound 各三个 seed，主表只取各模型验证内的双端未训练样本，训练内另列，另报剔除训练同条件重复后的验证；② New Free32 五 seed、三个冻结预算，在原固定 validation 上盲图前向，每 seed 416 行及同一组配对，各状态 `H`、`U` 都不含这些行；③ 180 个 New Free32 接受批，预测是采集前，真值只通过冻结后的已接收 ID 及 receipt 投影。没有读取历史 test 预测缓存作为 pool 或验证预测。早期共同 checkpoint 不让不同轨迹的反馈混成相同设计。
- 15 个模型的 checkpoint SHA、图缓存 SHA、验证 IDs hash、H hash、历史 NRMSE 与重放值都做核验；最大 NRMSE 差为 **2.8×10⁻⁸**。模型表每行给出 checkpoint SHA，`role` 记录双端是否曾训练：train=两端训练过，validation/feedback=两端未训练；不报告混合一端训练过的配对。Row 校验允许出现该分子的其他条件见过，不等价于新分子泛化；资格验证也曾用于选择 checkpoint，不是独立最终 test。

## 1. 正式 qualification：全局误差低也会遗漏一个方向

固定 row seed 42 的验证 V1/V2 MAE **1.381/2.192 mL**，combined NRMSE **0.2792**。以下局部数字都是分子等权；方向的分母是真实 `|Δ|>0.5 mL`，有符号且 `|预测Δ|≥0.1 mL` 才算明确方向。

| 因素（配对/分子） | V1/V2 真值平均 \|Δ\| | V1/V2 预测平均 \|Δ\| | V1/V2 差分 MAE | 明确同向 / 平坦（V1、V2） |
|---|---:|---:|---:|---|
| EA（80/63） | 3.391 / 8.499 | 3.662 / 9.483 | 1.484 / 2.317 | 同向 80.9% / 89.2%；平坦 10.6% / 1.7% |
| 上样 V（40/35） | 1.214 / 1.090 | 0.079 / 0.093 | 1.171 / 1.115 | 同向 31.8% / 10.5%；平坦 68.2% / 63.2% |

上样 `ΔW` 真/预测平均绝对幅度 **1.342/0.172 mL**、差分 MAE **1.253 mL**；V2 对有意义真变化还存在 **26.3%** 明确反向。剔除训练中完全同条件行后，上样留 38 对，两端比例 0.064/0.085，几乎不变。row 525 对两端幅度约 37%，row 1101 约 1%，三个 split 都偏弱而程度不同。三 compound 验证 seed 的等权平均幅度比，EA 为 0.687/0.695、上样 0.014/0.013；属于更难的化合物泛化切面，不与 row 合池。资格模型 seed 42 的 loading-solvent-volume 无支持，加载溶剂类别仅 1 对，不能排名。

## 2. 同验证配对的五 seed 预算对照（新增）

每 seed 先按分子等权，再等权汇总五 seed。每预算同一 160 个 seed-配对上样事件（每 seed 28–36 对，不是 160 个独立分子）；EA 为 469 个 seed-配对事件。每个 seed 的完整配对 ID、真实差分在三个预算完全相同。

| 预算 | 全局验证 NRMSE | 全局 V1/V2 MAE | EA 差分 MAE V1/V2 | 上样差分 MAE V1/V2 | 上样平均绝对差幅度比 V1/V2 |
|---|---:|---:|---:|---:|---:|
| L333 | 0.7514 | 2.662 / 5.154 | 2.742 / 5.489 | 1.154 / 1.610 | 1.16% / 0.42% |
| L525 | 0.5858 | 2.224 / 4.211 | 2.299 / 4.309 | 1.159 / 1.609 | 0.53% / 0.43% |
| L1005 | 0.3788 | 1.581 / 2.728 | 1.753 / 3.218 | 1.076 / 1.594 | 20.5% / 6.7% |

同比观察：全局 NRMSE 降约 50%，但上样 V1/V2 局部差分误差只降约 6.8%/1.0%。L525 已达全局改善但上样依旧全平；L1005 上样 V1/V2 的平坦比例 57.6%/67.6%，明确反向 5.0%/8.9%，同向 37.4%/23.5%。将真变化门槛从 0.1 改至 1 mL，平坦率仍在 V1 57–58%、V2 65–68%。平均幅度比不是近零差分的逐对除法；逐对比只在达到阈值后计算。bootstrap 分 seed 的区间保留在表，不平均区间端点生成虚假的跨 seed CI。

L1005 V1 幅度分 seed：157 **56.9%**、2357 **41.3%**，而 887/6101/12203 为 **0.25% / 1.46% / 2.67%**。V2 五个 seed 的幅度均 <20%，两个有改善的 seed 的 V2 仍比 V1 压缩重。五组结构类统计列在 `al_by_structure`；验证上样总共仅 28–36 对/seed，各亚类经常太小，且不同 seed 的类别样本可能重复，不能定论哪类普遍最难。流速在五个 split 共有 14 个 seed-配对事件，预测差为零；两种加载溶剂轴在五 seed 的验证检查各仅 1 个 seed-配对事件，不能作稳定模型评价。

EA 局部非线性也有进步：固定三点验证集，V1/V2 分子加权绝对弦偏差真值 **3.47/7.72 mL**；模型 L333 **2.68/5.57**，L1005 **3.32/6.77**，弦偏差误差由 **2.40/5.00** 降至 **1.49/3.05 mL**。上样量的验证三水平证据极少，不能把局部平坦直接外推成全曲线物理形状；样本更多的两点检验足以表明幅度不足。qualification seed 42 上样也仅两个可用三点序列，真弦偏差约 1.15/2.68 mL，预测约 0.002/0.001 mL，仅作为例证。

异常案例（不用于总体估计）：seed 157，L525，CAS 88-69-7 的样品由 50 增至 150 µL，观察 `ΔV1=-5.708`、`ΔV2=+0.550 mL`，冻结预测为 `−0.0083/+0.0100 mL`。样本 ID `6b8fefaf0647d2239858`、`0296d31e8c2e55602a19`；这是该预指定 seed/L525 中，满足 V1 平坦的案例按 `|真实ΔV1|` 排序的示例，不是典型中位水平。

## 3. 历史同批结果复算及可能机制

从原 freeze、接受 ID、选前 q50、反馈与 label-access receipt 重算全部 **180** 个 New Free 批；逐原定义（旧五条件、同分子、批内所有组合）重现 **165 物理对 / 330 端点**，每 seed×阶段统计与原表误差 <10⁻¹⁰ mL。五 seed 等权真/预测平均绝对差 V1 **2.696/0.263**、V2 **2.287/0.154 mL**；直接 pair 口径为 **2.525/0.393、2.370/0.235**。接受批是选出来的分布，不同预算批的组成变化不能归因于训练。严格重新配对与历史兼容表分别保存，无状态替代。旧 CW-only 状态没有同口径已接受池反馈，不能依靠冻结模型的 test_X 缓存补齐。

已支持的解释：样品量由 amount 条件残差通路提供；历史 AD/有限差分显示 backbone 在此方向导数为零，历史选定小样中 pre-ReLU 到 q50 的斜率吻合且未发现 q50 截零；这不支持“最终 ReLU 把上样响应统一削为零”。模型确有该输入、在 157/2357 能学到部分响应，不能说架构表达不了。`density×V` 数学上在跨密度时可能别名，但旧同分子、固定其他条件扫描无精确碰撞；本轮又固定密度，因此同一曲线上上样水平不会被该乘积合并。不能把低局部敏感直接归结为乘积丢失信息。

尚待区分：主任务/损失可能更奖励 EA、V2 整体位置和常见区域；条件分支相对分子主干梯度、训练批内匹配支持与噪声都可影响优化。历史两种简单旁路的负结果排除直接推荐同一改动，不足以判定加法残差、条件交互、监督不足或记录噪声谁是主因。下一阶段只改配对损失，将“模型有没有学到”与“哪个采集策略更好”分开。见 [决策](NEXT_STAGE_DECISION.md)。
