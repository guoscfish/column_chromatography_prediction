# System Prompt 与对照版本

[正式英文 Prompt](PROMPT_PURE_LLM_V3.md) 独立撰写。它定义按轮 B32 的整体 Row 分布预测目标，并区分结构、试剂、条件、当前预测、获取时预测、实测值、先验和假设。PE/EA 越高通常意味着 EA 份额越低，加载溶剂和流动相分别描述。V2−V1 是物理洗脱区间，分位输出宽度无 epistemic 校准承诺。当前头部的 q50 路径用 MSE，文本只称中心估计。Flow 和 Purity 提供物理解释，现有模型不把它们作为独立输入。

模型可自主取舍覆盖、局部条件对照、复测、结构类比和可迁移规律。它在一次回答中完成联合审查，词汇本身不会触发选点拒绝。结构化选择与证据应使用可验证坐标。函数只检查身份、数量、条件差异、引用和版本，有效 B32 的构成由模型确定。自由解释是否真正对应试剂、数值或机制仍依赖抽核。

[历史参照](PROMPT_LEGACY_REFERENCE.md) 来自 seed157 r00 正式 NoCW `request_00.json` 中系统消息原文，不由 paired 原型重新拼装。[Prompt-only 版本](PROMPT_V3_LEGACY_SCHEMA_COMPATIBLE.md) 使用原 user 消息和旧选点对象，名称、长 ID 与哈希回写保持兼容。原有输出类型、直接 validator 和本地严格 JSON 解析均保存为可明确比较的层。新版独立 Prompt 不依赖旧文替换。核对每份历史请求或后续消融的真实消息和摘要，避免把 Prompt 文字差异误称为纯效应。
