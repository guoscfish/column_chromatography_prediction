# 完整候选池与无损序列化

从正式 NoCW 冻结目录读取就绪状态。核对 split SHA、角色全集、历史 batch freeze、目录和首次外发输入的 SHA，逐轮从 U 移入 L，并核对过去已执行的反馈收据。新版 selector 读取过去的落盘观测和当前 U 的预测；新实验标签仍在训练端。字段来自 [字段矩阵](field_availability_matrix.csv) 与冻结公开表。条件按 sample_id 连接，分子按 canonical SMILES 绑定。Ending time 和来源行号留在审计端。

Layout A 按历史实际首次请求的显示顺序保留列式 L/U，适用相同状态对照。Layout B 按稳定分子 ID 排序，先同分子 O 后 C，组内保留 A 的相对顺序。两种视图都提供全部 3330 个允许训练池身份，验证/测试行不参与排序或展示。实测标签只附在 O。首轮 333 O/2997 C，第二轮 365 O/2965 C，终止预算为 L1485。分子、试剂、同完整条件的不同实验行保持各自身份。

压缩时将分子结构与描述符放入字典。折叠相同的 q50 别名和恒为零的 pending 相似性，保留原 q10/q50/q90、宽度（含负值）、已有新颖性和相似性字段。恒定的柱规格作为全局条件。CAS、试剂名称和纯度字段经零基 reagent_index 恢复；同一分子可关联多份试剂记录。每一列恢复时按固定列名 zip，每次构造对两角色做完整 round-trip 相等检查。样品条件保留 raw 精度，EA 份额是记录比例的派生科学读数。O 同时保留历史获取时中心预测、误差和轮次。持久事实账本保存采集理由、身份与相应 checkpoint。未来 V3 回合另存完整选前六分位预测。此前历史反馈仅提供已落盘的获取时预测与误差。

A0/A1 按字保留历史 user 消息。A2 保留旧字段和顺序，追加新版 metadata。A3 使用角色 ID、宿主绑定和独立视图；A4 启用无损压缩；A5 切换分组；A6 切换结构化输出；A7 切换持续记忆。A3 的旧式近期反馈也会迁移为受控投影，相关相邻差异要按组合解释。A0–A2 保留历史关键词校验以对照旧合同，A3 起允许模型提及相关理论。所有新修复请求均避免回放被拒的自由文本。A4 为静态输入压缩对照，实际候选池完整性在每个 arm 单独核对。序列大小与近似统计见 [示例测量](examples/serialization_comparison.json)。

固定顺序和短编号可以改变位置偏好。诊断按最初显示位置、分子内位置、号码区间与末位数字比较。所有位置指标来自离线审计或后续成对评价，不回流选点。新版为字段补齐承担输入成本，压缩收益使用同字段对照量化。
