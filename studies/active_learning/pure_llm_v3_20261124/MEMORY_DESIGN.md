# 持久科学记忆

同一轨迹的记忆由不可变事实、轮次计划和版本化假设组成。快照包含 seed、版本及全内容 SHA256。持久文件的可信来源仍由冻结状态、运行 receipt 和运行绑定确认。每条观测按底层 sample ID 保存，已登记测量、条件、获取时预测、误差与 checkpoint 不能被后续写入覆盖。历史原因和引用与当时的选择、模型 checkpoint 和可见身份一起审计。采样候选卡存在时，轮次记录同时保存当时的六个分位预测。选前事实始终经已授权的观测卡进入，无须由 selector 请求标签。

`acquisition_round` 对应作出选择的轮次。获取时误差是该轮点预测减实测，记录符号；当前模型的残差无法从这些旧误差推出。早期观测按初始化事实处理。模型每轮看到的最新反馈从可见观测按最近获取轮次投影，包含数值结果与获取时预测和误差，对照仍使用当前 O 身份。快照保留完整版本，即便同一条引用换用其它编码，底层身份仍一致。

每个假设由 LLM 首次分配一个 H 编号。后续操作显式给出当前版本、修订理由、证据角色、状态、信心、尚待回答的问题和对模型学习的意义。初版把命题正文作为稳定身份的一部分，复核原命题时通过版本更新证据、置信、状态与未解决问题；改写研究对象或反转命题方向时另建 H 编号。既有支持和反证随版本保留，LLM 允许在解释后更改证据所支持的方向，原角色仍见旧版本。归档与重新启用由 LLM 提交，Python 保存操作和版本并验证引用的可见性。归档摘要可帮助识别曾处理的命题，完整证据版本仍留在轨迹快照。
