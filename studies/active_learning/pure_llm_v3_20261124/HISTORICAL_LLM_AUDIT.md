## 分母和可复现范围

本次使用实际执行的四类 4g Row 全目录轨迹。历史 Free32、新 CW-visible Free32、NoCW32 各覆盖五 seed 从 L333 至 L1485 的 180 批。旧 CW16+LLM16 覆盖 157 的 36 批、6101 的 35 批，分别至 L1485/L1453。旧组的 LLM 选择数为每轮 16，另有 16 个预留实验；表中的 legality 以各 arm 自己的合同为准。NoCW 的旧 59 批是 180 批的前段子集，L1005/L1389 迁移副本按正式 L1485 authoritative owner 去重。另逐文件核验早期 CW＋LLM16 shortlist screen 的 6 批，全部 16 条原答与最终条目顺序一致，任何一批均无 fallback；其候选子集、单轮 conversation 及未知模型快照与全目录合同不同，另列在清单中。数值 Hybrid32 的三个模型成员和离线代理评估没有 LLM 回答分母。后续 GPU 数值运行也没有。

直接核对 611 个 `batch_freeze.json` 的请求输入、目录、决策、合同、原始已完成回答、反馈和标签访问回执；另扫描两组 gzip ledger 共 528,855 个归档记录，逐行重算原字节 SHA。冻结绑定验证共 356,196 项，其中 5,360 项使用本地原件、350,836 项使用逐字节验证的归档。历史 SDK 全量外发结构在落盘格式上不完整，Free 的 270 个旧请求使用 11-17 既有逐字节 hash 重建证明，不能生成不存在的物理网关回执。Hybrid 可验证 turn、目录和选择，旧 SDK request 和成功传输 ledger 的覆盖更弱。选前 `L/U` 与 catalog、packet 的全集逐轮核对。反馈值只来自过去已冻结执行的选择；本次未打开数据真值表、验证或测试真值。

回放 [audit_history.py](audit_history.py) 只导入既有 AST 校验提取助手及 Python 标准库。它验证精确文件、请求 hash、客户端 user 消息对应完整 packet，检查候选/测量/预留的身份集合，重新调用对应版本的纯 validator，并将阶段和个案以 CSV 输出。每个答复只按 turn 计一次。公开快照不随 Git 分发全部私有 request/catalog，缺原件的环境只能验证现有归档和读取派生表。可核验 SHA、方法归属、覆盖和缺失路径见 [审计清单](historical_attempt_manifest.json)。

清单另列 304 份重复或迁移副本、18 份早期 query 协议冻结、1 份缺揭示回执的冻结、54 个未封存或未完成的目录和 13 个 mock 冻结。查询本身可能是一次完整回答，同时还只是中间工具轮，故早期交互的首份返回、候选可见性及选点数不与四类全目录协议混算。Dual Expert、EPIG、数值方法和其他非四类研究设计未纳入本次选择器分母。原报告的阶段变化与对照定义见 [当前实现审计](CURRENT_IMPLEMENTATION_AUDIT.md)。

## 科学语义与可客观复核的边界

程序复核 ID、标签归属、可见条件和冻结时点。旧 validator 能通过识别出域、归属或结构的问题，无法用自由文本保证实际分子、数值和比较条件。固定抽样与显式 m编号规则命中后人工逐条复核，在 CW-Free 最终 5760 条 choice 中确认 25 条错绑，另有 1 条跨分子和多因素被写作 matched loading contrast；12 个编号表面不符案例实际是有效跨分子类比。该检出范围内语义错绑是下界。旧 Hybrid 的确定病例为 6101 r9 自由描述把未知行写作已测结果；157 r9 的未知 ID 是明确排除，不计成肯定的实测引用。 [核对个案](semantic_binding_cases.csv) · [Hybrid 与旧 Free 逐条语义审查](../verifiable_scientific_agent_20261030/SCIENTIFIC_ISSUE_REVIEW.md)

- **洗脱方向与化学先验。** 2357 r20 明确纠正“高 PE/EA 是更强洗脱剂”的旧说法，并引用同 m72 的 2/1→5/1；12203 r14 文字中的 stronger 与其引用的 PE/EA 方向仍相反。EA 记录份额等于 `b/(a+b)`，较高 PE/EA 对应较低 EA 份额。一般物理趋势不能约束个别结构和实验成严格单调。
- **上样字段与条件归属。** 加载液 PE/EA/DCM 与 PE/EA 流动相承担不同实验角色，`V/ul` 与加载溶剂体积是独立字段；`Density g/ml × V/ul` 给名义 mg。只有旧五字段相等不足以证明其他记录条件一致，尤其 Flow、Purity、试剂身份；V3 的元数据复核报告逐 pair 保留跨分子、多轴、复测记录和仅依旧字段的结论。
- **时点与不确定性。** r9 同一已测行的预测是 r9 获取时模型的预测。将它与 r10 新点的当前预测一起称为同 checkpoint 曲线会混淆时点。区间宽度 `q90−q10`、物理洗脱宽度 `V2−V1`、历史预测减实测是不同量。q50 用 MSE 训练；负宽或端点次序违反实际是原输出异常，不等于比其他点更有采集价值，且 LLM 无法凭分位宽判定 epistemic 或校准分位性质。
- **命题版本和证据方向。** 6101 r35 的反转幅度缩小且没有消去符号，原 H6 将改为相反句子的命题标为 rejected，版本主体不清。对反例实际存在、证据是否足量、条件效应是否可迁移，需要保留具体实验关系与正反来源。上面的条目是事实例和判读规则，没有为全轨迹估算非结构化语义错误率。

## 记忆、位置和上下文

- 三类 Free32 各 175/175 次连续轮的 `recent_outcomes`、`previous_hypotheses` 与同 trajectory 前轮反馈对象精确相同；旧 Hybrid 69/69。逐字重复的假设文本分别为 13、65、55、2 次（旧 Free、新 CW-Free、NoCW、旧 Hybrid）；相同 ID 对应文字变化 582、605、423、216 次，混合了合理修订、正常新内容和 ID 重用。未能从最近一轮精确文本找到 rejected 命题直接重现，不能排除隔轮或改写重现。Top-8 获取轮年龄、引用和近期反馈使用逐批记录在 [记忆表](memory_diagnostics.csv)。
- 最新 CW-Free 的旧逐引用统计，早至晚 Top-8 引用占比约 20.04%→5.97%，引用分子 HHI 约 0.0913→0.0807。因此没有历史证据支持“随着轮次越来越集中于少数历史极端误差样本”的概括。保留/移除 Top-8 的制度效果需要独立比较。
- 旧 Free、新 CW-Free、NoCW 的初始完整 packet 原序列化约为 1.67–1.77 MB、1.67–1.77 MB、1.62–1.72 MB。保存请求和 provider input/output tokens 分开统计，早期 SDK 重建列所示是 messages UTF-8 小计，不能和含 config 的存盘 request 字节直接比较。请求会累积完整旧答与纠错。输出长度、模型版本和纠错时点随实验共变。
- 三类 Free32 的接受批精确使用显示表前 32 项且顺序一致分别为 25、40、62 批。整批平均归一化显示位置分别为 0.340、0.273、0.228。旧 hash 排序相邻候选同分子的边约 0.54–0.56%。这些是位置描述，包含纠错后的前缀行为，不能据此判定位置偏置机制或短编号数字偏好。短编号、排序与任务展开方式需要同状态对照。

完整重放结论与已知人工例外见 [纠错输入证据](../volume_response_retry_audit_20261117/RETRY_CONTEXT_AUDIT.md)。已有 archive 中客户端请求每轮都续接完整旧对话；85 个新 CW-Free 纠错批仍出现较大选择/理由漂移。客户端证据无法证明服务商内部没有截断、修改或透明重路由。
