# PureLLM baseline 资格

已有 L/U 角色、历史响应和 QGeoGNN 输出限定了可提供的信息。实际请求使用白名单结构、同种子已冻结轨迹、完全一致的角色集合、条件 sidecar 和程序摘要。只有 L 角色可承载测量。允许分子描述符、来源明确的模型分位输出及与已测结构的历史同类相似性。相似性是一项只读特征，程序不据此排序、筛选、限额或替换。A 保留历史顺序，B 使用固定结构顺序。

新版摆脱历史梯度 bank 和 CW 距离，复用卡片富化只执行化学描述符、已有新颖性/相似性和宽度计算。独立下一步训练从冻结的 L333 初始化、同种子 RNG 和固定归一化开始，沿用原 benchmark batch size、Adam、学习率、早停和 validation checkpoint 规则。训练只接收确认过的 L 和训练端 validation。预测产物只以当前 U 导入 selector。验证/测试真值不出现在请求、记忆和修复见证里。持久记忆的观测值来自已测表，假设和判断来自同一模型轨迹，宿主负责版本与引用。

旧 paired 原型的 `audit_no_cw()` 扫描序列化键与值，也扫描前次历史对话。某些旧路径会因此拒绝仅包含相关理论词汇的回复，一旦把原回复接在纠错请求前又扫描整段，对话可能在下一次传输前再次失败。新版不因知识术语触发拒绝，也不转发原始非法回答、provider 错误文案或外部日志。修复外发视图只传操作范围、确定性问题路径和受限类型的选择、身份、条件轴及证据坐标。宿主保留已验证部分。自由理由的复杂科学主张仍需盲审。

选择执行入口与真实揭示/正式拟合分别授权。本阶段例子来自过去已可见测量，合成模型答复显式标明 mock。“纯 LLM”是选择权归属，Prompt、身份、顺序、持久记忆和交互行为都应做实验对照。
