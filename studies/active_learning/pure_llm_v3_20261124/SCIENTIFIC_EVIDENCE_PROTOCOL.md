# 科学证据与身份校验

PureLLM-V3 的计划包含简短的批次策略、32 条 `choices`、可选假设更新、反馈解读和批次复核。局部校验在冻结的选前状态内完成，读取候选条件、可见观测和当前假设版本。每个 choice 以 `candidate_id` 指定实验，以 `molecule_id` 和至少一个 `condition_anchor` 字段绑定其实际分子及条件，`reason` 记录学习目的。

| 对照关系 | 确定性校验 |
| --- | --- |
| `observed_evidence` | 引用必须来自选前观测集 |
| `prediction_comparison` | 引用身份和角色匹配，两条记录不同 |
| `single_factor_contrast` | 同结构、完整条件可比，恰好只有声明的实验轴变化 |
| `condition_response` | 同结构且至少一个记录轴有变化 |
| `replicate` | 两个不同实验记录，同结构，完整条件可比且一致 |
| `multifactor_contrast` | 同结构，至少两个记录轴有变化 |
| `cross_molecule_analogy` | 两条记录的分子结构不同 |

`reference_kind` 显式区分 `observed` 和 `candidate`。预测比较可以引用当前候选，假设的支持及反证只能引用选前观测。完整条件比较沿用 metadata sidecar 的 CAS、柱规格、原始纯度、密度、样品体积、上样溶剂及体积、PE/EA 和流速轴。比较对数值和等价 PE/EA 比例采用确定性规范，保留原始精度和文字以供 anchor 精确引用。单因素和复测声明要求条件齐全，因此缺少记录的轴会得到明确诊断。样品体积和上样溶剂体积独立比较。

`reason` 中出现的完整可识别 ID 应与已绑定的候选、分子或有效结构化引用一致。用普通语言写的分子名称、推断方向、因果推理和预测可迁移性仍需人工科学复核。自由文本声称某关系时，建议通过 `references` 表示其可检查事实。实验理由可以讨论主动学习理论，接受规则检查输入来源、数据角色和明确的事实关系。

接收端始终使用严格 JSON 解析和本地校验。响应只允许一个完整 JSON 值，可包裹一层完整 JSON 代码围栏。重复键、非有限数字、截断 JSON 和附带正文均产生格式诊断。JSON Schema 是本地契约的可读结构描述。服务端是否强制执行同一 Schema，待获授权后按固定模型与端点单独验证。
