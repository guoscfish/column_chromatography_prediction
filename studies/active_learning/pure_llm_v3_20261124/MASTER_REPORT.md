# PureLLM-V3 研究交付

PureLLM-V3 已形成离线合格的独立候选 baseline。它只接受 LLM 提交的 32 个实验，具备完整候选和观测输入、试剂元数据、角色 ID、证据校验、版本化记忆、局部修复和有界传输。选择与真实揭示/拟合分成两个独立入口。本阶段真实付费 API 请求 **0**，新增标签揭示 **0**，正式模型训练 **0**。

## 十三项研究问题

1. **历史遗漏字段。** Flow、Purity、CAS 和 name 都在 raw 和 canonical 中，未进入历史 NoCW 的实验卡。4g 柱规格及 PE/EA 体系适合作为全局说明。Ending time 和来源身份留在后台审计。raw 4/5/6/8/10 mL/min 频数为 8/371/12/11/3841，canonical 为 8/371/12/11/3761。 [字段审计](DATA_FIELD_AUDIT.md)
2. **当前模型和 V3。** Flow 用于原始时间换算体积。Flow、Purity 无独立 predictor 通道，V3 都直接获得，并区分纯度比例、等级和缺失。canonical 保留 4163 行、217 个结构，Row split 仍使用 333/2997/416/417。
3. **伪重复和伪单因素。** 旧五条件相同的 309 个重复组里，287 组由 Flow 或 Purity 拆开，完整条件下仍存在 31 组可能复测。377 个历史 NoCW 单因素诊断配对中，30 个重分类为多因素。历史 Free seed12203 r20 的 DCM plug volume 比较也由 AR 对数值纯度的变化拆开。 [对照复核](historical_contrast_reclassification.csv)
4. **历史主要失败。** 已测/已选误选、非法长 ID、绑定哈希抄错、候选与实测证据混淆、合法 ID 与科学描述错绑以及整批重答漂移。NoCW 首答合法 70/180，重答批首次合法选择保留 1042/3157。新 CW-Free 的 173511 条物理终态记录主要是 429、连接失败和 403，完整回答共 430 份。 [历史审计](HISTORICAL_LLM_AUDIT.md)
5. **Prompt 能处理的问题。** 目标、洗脱方向、上样字段、实验物理与模型信号解释、选择和证据核对、正反证判断及一次调用内的批次复核可用 Prompt 改善。实际影响需要与 A0 成对比较。 [Prompt 设计](PROMPT_DESIGN.md)
6. **需要协议的问题。** 短角色身份、宿主 SHA、同状态映射、全池位置、C/O 证据引用、局部修复锁定、持续记忆和有界恢复需要宿主机制。A4 用试剂字典和常量压缩，A5 才改变显示顺序。
7. **模型表达边界。** Flow、Purity 不可作为独立输入学习，density 和 sample volume 在 predictor 用名义质量组合。向 LLM 提供这些字段可使物理判断更完整，模型是否受益需要单独实验。此阶段无 predictor 架构和训练参数变更。
8. **已消除的执行路径。** 对未测标签、跨状态响应、非法 ID、错误角色、重复选择、错误结构化身份、伪单因素和未授权补丁 fail closed。模型输出未完成或无法判断服务端执行时停止。相同完整回复和冻结结果复用。无 Random、外部分数、梯度 bank、限制配额或宿主补点路径。 [协议验证](OFFLINE_TEST_REPORT.md)
9. **仍待验证。** 真模型首答、自由文本科学绑定、分组和短编号偏好、长期记忆收益、实际运行成本和代理能力都待实验。GPU 适配已接入既有训练函数，当前轮未运行实际拟合或 CPU/CUDA 固定标签一致性比较。服务同名模型的隐式版本仍不可凭历史字符串证实。
10. **纯 LLM 资格。** 所有新增选择由 LLM 决定，宿主只处理可见事实和合法性。历史诊断和数值策略表现留在审计文件，不接入请求。A7 默认取消固定 Top-8 突出，M1 允许对照；历史结果并未证明取消一定更优。 [纯度审计](BASELINE_PURITY_AUDIT.md)
11. **学习效率评价。** 先比较同一冻结状态的科学方案和工程表现，再从同一 L333 按真实闭环比较 validation AULC、NRMSE、R²、预算端点及成本。任一 arm 的合法选择保持原样，数值策略仅作为独立比较组。评价不借用历史 test 调参。
12. **下一阶段预算。** 首轮最小实验冻结五 seed × 两个状态 × 三个 arm，共 30 份基础逻辑请求。偏差来源需要细分时补 A2–A5，最多 40 份。最小连续记忆对照从两个 seed × 两种记忆 × 三轮开始，共 12 份。阶段一单条件两份逻辑回复、每份两次物理尝试，全部 30 条件的物理请求上限 120。 [预注册草案](REAL_LLM_PILOT_PROTOCOL.md)
13. **公平性和剩余风险。** 显示顺序、短编号、metadata 和不同 schema 改变注意与输出负担。A3 还更改了历史反馈的投影，作为组合变化报告。历史 test 的部分曝光有记录，不能称为新独立测试。固定服务版本、推理、预算、模型 checkpoint、设备和 L/U 并盲审解释。只根据真实 provider usage 核算成本。

## 审计覆盖与未解决问题

实际历史审计覆盖 611 个全目录冻结批次和 6 个单列早期 shortlist Hybrid 决策、1,213 份完整回答、528,855 条逐字节 SHA 归档记录，另列 304 份重复/迁移、18 份早期交互冻结、54 份未完整目录、13 份 mock 与一份未揭示冻结。核对了指定 seed/round 漂移案例。四组已接受历史批均通过当时适用校验，其中一个需要既有手工转录授权才与冻结方案一致。缺失的旧 SDK 成功传输回执、账单记录、未完成调用与服务端行为留作未知。数据分布部分单列 1,199 个可接受批次标记、1,525 个独立 L/U 状态以及 25 个未纳入标记。

本机和远端进程状态未能实时核验，原因分别是进程查询被系统拒绝与只读 SSH 探测 DNS 失败。GPU 审计以现有带时间和哈希的任务收据为据。未覆盖、清理或终止既有工作。旧头指针与本地 origin/main 一致，均为 `b6b03b9eb62ebc75b7e60a10fbe078492d7efd92`。 [实现与运行证据](CURRENT_IMPLEMENTATION_AUDIT.md)

## 文件与复现

所有交付集中在本目录。 `pure_llm_v3/` 包含 metadata、身份、输入、Prompt、schema、校验、记忆、纠错、传输、选择、回放示例和训练交接。 `tests/` 包含单元与离线集成用例。 `examples/` 包含完整 JSON 示例及序列测量。审计代码、配置、CSV、JSON 和设计/计划文档一并交付。逐文件新增清单、SHA 和长度见 [SHA manifest](artifact_manifest.json)。旧路径无本任务修改。

34 项离线测试通过，拟议的 30 个 pilot 条件已全部离线构造。实际测试命令及输出见 [离线验证](OFFLINE_TEST_REPORT.md)。 [运行入口](README.md) 包含可复制的 30 条件离线 staging、另行授权后的真实单条件和后续单轮 GPU 拟合命令。阶段一之外的真实运行均留待后续阶段。
