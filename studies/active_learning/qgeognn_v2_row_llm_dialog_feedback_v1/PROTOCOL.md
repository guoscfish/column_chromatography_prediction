## 独立上下文和审计限制

每个 seed 使用一个全新 projectless Codex 任务，不 fork 开发对话。只传该轨迹当前数据包、程序返回的查询结果和前序本轨迹反馈。两 seed 任务独立；无旧策略排名、测试成绩、其他轨迹标签、仓库路径。程序查询接口只有四个白名单操作，不能读取任意文件或执行代码。

产品仍提供原生工具，不能宣称硬隔离。接受输出前，程序审计该任务完整原始 rollout：出现任何原生工具调用即拒收，不揭示该轮标签。模型固定为演练核实的默认 gpt-6-sol / high；漂移即停止，不自动切换。保存模型元数据、消息摘要哈希、最终 JSON、查询和费用用量，不发布隐藏推理或系统指令。模型标识由实际任务核验。

每轮固定：最多16次助手回答、12次目录检索、240个不同候选详情（含20个初始参考卡）、每次最多24条。允许批量检索和一次补充检索；预算耗尽不能随机补选。选择器可以选全合法 U_t\CW16；128数值候选仅作参考。不设新分子或同分子配额。

L333真响应可检索，不给训练内误差；后续反馈使用冻结的测量前预测。V1/V2均为mL，V2−V1是洗脱区间跨度。原始已测记录全保留，支持同分子条件、结构描述符和Morgan相似性查询。假设区分化学先验、观测和未验证推断。

## 恢复与交付

入口 `scripts/studies/run_qgeognn_v2_row_llm_dialog.py`：prepare / validate / execute --seed / bind --seed --round --thread-id [--first] / process --seed --round / report。

`execute` 停于 AWAITING_DIALOG 后，将该轮 `dialog_prompt.txt` 原文交给对应独立任务。首轮完成后 bind --first；后续轮须先 bind 再发送新数据包。process 产生 QUERY_RESULT 时，仅转发 message_path 文件原文；得到 SELECTION_ACCEPTED 后继续 execute。每条消息仅发送一次；恢复先查已有任务输出，再 process。最终32IDs由程序检查并冻结。完成的选择、冻结、标签反馈和训练均复用，不重复调用。

原始 rollout 在本机 Codex sessions；审计归档保存可核验前缀哈希，移机恢复需一并保留原始文件（不纳入公开 Git）。训练大文件按仓库惯例本地保留；选择/反馈/指标/协议与报告提交。

报告分别列 seed 和均值、各预算误差、AULC、L525、实际查看与全池大小、名单外选择、结构条件覆盖、代表性假设证据、调用次数/token和训练秒数。订阅接口未提供货币成本，不能推算为零。后续仅建议同预算去反馈对照，再考虑身份隐去和独立更大seed集合，不自动扩展。
