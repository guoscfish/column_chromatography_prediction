# 阶段决策：完成 Phase 0，暂不进入付费 Phase 1

日期：2026-11-03，Asia/Shanghai。**本次执行到此停止，不启动后续付费实验、QGeoGNN训练、新标签揭示或多seed AL。**

## 1. 明确结论

**现有证据不足以支持正式 GP-guided LLM，更不足以声称其已改善学习效率、稳定性或可靠性。** 它支持继续开展受控机制研究：固定 r00 模型的残差风险排序有信号；联合条件信息增益可正确、稳定复算；三臂共享基线和控制前后变化可以审计。然而响应 GP 的名义90%区间实际覆盖只有61.5%–74.5%，当前 checkpoint 的风险适用性也没有验证。

**仍需补充可信的 GP 不确定性。** 数值求解成功、均值优于弱常量基准、风险排序相关，均不能代替概率校准。不能将已有 IVR 单位噪声或 QGeoGNN 分位宽度直接作为已校准不确定性。Raw/CW均未通过响应可靠性筛查；不选择有利端点、seed或指标宣布通过。

**控制器优先研究可复算的联合条件信息增益与高相关冗余审查，并保护严格单因素局部对照。** 它们不依赖读取未来标签，定义清楚，也能由批次协方差、噪声和原始条件复核。IG下界只能与预先冻结、相同实验域和结构的参考比较；全局覆盖提高不作为正确性目标。初期应先诊断、再在独立开发状态校准是否值得触发修正；未校准不发真实控制指令。

风险盲区硬要求暂缓：缺乏当前checkpoint、当前候选域的合格风险证据时，应明确不可判定，不自动变成固定GP配额。单因素结构豁免只证明对照结构，不证明化学假设正确，也不无限豁免整批质量。

## 3. 下一项最小实验

下一项工作应为**一个无付费的、独立历史block上的概率校准补证实验**，而不是立即调用LLM。

1. 在看新核验block结果前，登记一个已有冻结checkpoint及其未参与训练的已观测后续批次；标明采样机制、分子/条件关联和监督时点。不能拿本次后96点反复调参，也不能把同数据新seed称外部确认。
2. 将已有诚实误差分为拟合、开发校准和冻结核验block。比较原线性GP与一个事前定义的简单噪声/尺度校准，冻结区间目标、评分、宽度约束、可接受偏差及失败判据。先解决可解释的失配，不自动扩到DKL/LoRA或大量核搜索。
3. 逐V1/V2报告NLPD、CRPS、区间覆盖和宽度、尾部/条件分层，并以block为单位报告不确定性。风险模型明确旧固定checkpoint与当前checkpoint的区别；无法验证迁移就不放行当前风险字段。
4. 只有可靠性适用范围清楚后，再在开发状态上校准并冻结数值控制阈值、局部参考域及豁免规则。不得按A/B/C最终学习收益倒推阈值。

这项实验也**未在本次自动执行**；当前核验输出和失败结果保持不变。它只需已有已观测数据与低成本GP，不需要LLM、新QGeoGNN拟合或test真值。
