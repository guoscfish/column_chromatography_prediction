# 研究问题、可证伪假设与证据等级

日期：2026-11-03，Asia/Shanghai。本研究对象为 4g Row-split、QGeoGNN-V2、L333 起点、Batch=32。目标是改善重新训练后的 QGeoGNN 对 V1/V2 的预测泛化误差。GP 是待验证的数值专家，不以 GP 自身精度或色谱条件优化替代最终目标。

本次仅执行 Phase 0；下述后续实验和继续门槛属于待冻结协议，不授权 LLM 调用、标签揭示、训练或扩展预算。实际发现见 [OFFLINE_REPORT.md](OFFLINE_REPORT.md)，阶段决策见 [NEXT_STAGE_DECISION.md](NEXT_STAGE_DECISION.md)。

## 1. 中心问题及正确基线

中心问题：**数值引导和决策约束能否提高 LLM 驱动主动学习的收敛效率、稳定性和可靠性？**

当前 CW-Free 本来就提供 QGeoGNN 预测、分位宽度、CW 距离、分子/条件新颖性、相似性以及已有科学反馈。因此 Arm A 统一称为 **LLM-led / unconstrained numerical decision baseline**，不称为“完全无数值信息的纯 LLM”。所谓 unconstrained 指没有新增 GP 决策质量约束；合法 ID、唯一性、证据引用及响应协议仍严格执行。

| 比较 | 唯一科学干预 | 要回答的问题 | 不能由此推出 |
| --- | --- | --- | --- |
| A 与 B | 增加经过可靠性门槛的 GP 数值信息，LLM 自由使用 | 概率信息能否改变决策，并改善后续学习？ | 仅选点改变即证明泛化提高 |
| B 与 C | 相同 GP 信息基础上，数值控制器可要求修正完整 32 点提案 | 数值约束能否额外降低波动、低质量批次和学习成本？ | 多请求带来的任意重新采样一定属于数值控制收益 |
| A 与 C | 数值信息与决策控制的整体框架 | 整体框架是否提高学习效率与稳定性？ | LLM 必须优于所有纯数值方法 |

现有 raw LCMD、CW-LCMD、固定核 IVR、MaxDet 和 Numerical Hybrid 作为强基线及机制参照。CW16+LLM16、GP16+LLM16 不作为本研究新方法。

## 2. 可证伪假设

**H0：GP 概率信息的可用性尚未建立。** 已观测 V1/V2 响应 GP 的均值、潜在函数方差和观测预测区间，可能与既有 IVR/CW 信号高度重合，也可能校准不足。若诚实留出上的适当概率评分不优于训练侧基准、覆盖失配，或来源不能证明不泄露，则不得将其发布为“已校准不确定性”。数值稳定运行本身不足以推翻 H0。

**H1：风险 GP 可识别当前 QGeoGNN 的高误差区域。** 只有合法 prequential 或 out-of-fold 误差才可用于此检验。初始 L333 的训练内残差不能充当泛化风险监督。历史 acquisition-time 残差来自不同 checkpoint 时，模型状态、预算、预测时点、目标缩放和来源必须分别登记；不预设它们是固定模型下的同分布样本。若分状态验证无预测增益、样本不足或状态迁移无法识别，结论为失败或不可判定。

本次实际离线方案将 seed157/6101 的固定 r00 checkpoint 与初始 bank 绑定：响应 GP 在 L333 上拟合，以随后已经观测的前 6 批作 forward 核验；风险 GP 使用该同一个 r00 的事前预测与随后已观测响应计算误差，前 3 批拟合、后 3 批核验。因此它检验的是**固定 r00 模型的误差代理**，不是不同 acquisition checkpoint 残差的混合，也不是后续当前 QGeoGNN 的泛化风险。后续 checkpoint 状态迁移仍是单独问题。

**H2：B 的 GP 信息提高决策质量。** Phase 1 先检验 B 是否实际使用 GP 信息，以及选点的信息增益、风险分布和重复调用波动如何变化；这些是机制指标。只有 Phase 2/3 的 QGeoGNN 误差和 AULC 才可支持学习效率改善。B 未改变决策、改变方向不一致或后续学习不改善，均属于可接受的负结果。

**H3：C 的数值控制提高稳定性和可靠性。** 相对 B，C 可能降低预注册的低信息批次比例、无解释的高相关冗余和重复调用间数值诊断波动；也可能损害有价值的局部条件实验，或只增加成本。必须记录控制前后变化与豁免，不以“最终合法”代替质量效果。若 C 只改善其强制约束的分数而不改善短程 AULC，不能宣称学习效率提高。

**H4：整体框架改善平均性能及尾部表现。** 正式多种子阶段同时看平均 AULC、跨种子标准差、高分位/最差 AULC、达到固定误差阈值的预算。若均值改善而尾部恶化，需原样报告权衡；若 C 对 A 没有稳定优势，应报告负结果，不通过改阈值、删种子或换指标制造优势。

## 3. 不确定性与风险是不同对象

1. 响应 GP 的方差表示该 GP 在指定表示、核和噪声模型下对 V1/V2 的条件不确定性，不自动等于 QGeoGNN 的误差风险。
2. QGeoGNN 的 q90−q10 是现有单模型分位预测跨度，可能交叉，不能自动称为 epistemic uncertainty。
3. 固定核 IVR 的单位 prior/noise 是已有代理假设，不是经标签校准的概率事实。
4. 风险 GP 若以合法误差为响应，应明确预测的是带 checkpoint 条件的误差量或其变换；预测“误差代理”不等于掌握未测候选的真实误差。
5. 用当前 checkpoint 的梯度表示对当前 L 做 GP 交叉验证时，表示可能已经学习过留出点标签。即使 GP 的拟合子集排除了这些点，也只能称为“固定已训练表示上的回顾性留出”，不能冒称完整流水线的诚实 OOF 或未来校准验证。

## 4. 证据与评价层级

| 阶段 | 可形成的证据 | 本次状态 |
| --- | --- | --- |
| Phase 0 | 权限、来源、数学计算、数值稳定性、历史已观测数据上的回顾性可靠性线索 | 本次执行；mock 与真实数据结果必须分列 |
| Phase 1 | 同状态决策差异、信息使用、触发/修正机制、重复调用波动与成本 | 只准备协议和 mock，未授权真实调用 |
| Phase 2 | 同状态分支、有限开发种子、短程 QGeoGNN 误差与 AULC | 未执行 |
| Phase 3 | 冻结方法在独立登记的多种子评价中的平均、尾部与成本 | 未执行 |

历史 seed 157、887、2357、6101、12203 及已经参与方法开发的相关状态均属于开发证据。更换随机 seed 并不能自动消除相同数据集、重叠样本及历史 test 曝光带来的限制。正式确认必须先冻结开发/确认边界及评价来源，不能把历史开发 seed 改名为外部确认集。

## 5. 判定规则

GP 可靠性需要来源可信、可复算概率评分、覆盖及区间宽度、跨状态敏感性共同支持；任一必要条件缺失就报告不可判定。具体数值与数据准入条件见 [GP_METHOD.md](GP_METHOD.md) 和 [EXPERIMENT_PROTOCOL.md](EXPERIMENT_PROTOCOL.md)，不得仅因均值拟合好而放行概率信息。

控制器先采用数学定义清楚的联合条件信息增益下界及高相关冗余审查；几何覆盖、历史误差邻域和严格单因素对照联合展示。全局覆盖更高不是预设正确目标，有明确结构的局部条件实验可依预注册规则获得有限豁免。不能从文本理由推断化学假设已被证明。

主效应以配对差和完整分布报告。单个 seed、轮次或同状态 LLM 重复不构成独立数据重复。服务端版本、调用时点、模型训练随机性、数据 seed 与 LLM 随机性分别登记。出现失败、不可判定、成本上升或方向不一致时，保留其分母与原始结果。
