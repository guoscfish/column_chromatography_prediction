## 1. 基线身份与可复用协议

Arm A 锚定 `free_cw_sol61_xhigh_five_to1485_20261101/frozen_source`，不锚定随时变化的工作区 selector。通用 `scientist_study.py` 将 `SYSTEM_PROMPT` 设为 `scientist_full_delivery.py::DIRECT_PROMPT`；正式 CW-Free 的冻结 runner `scripts/studies/run_free_cw_sol61_five_20261101.py::activate()` 进一步覆盖 `s.prompt` 和 `s.validate_plan`。其实际 prompt 为 `DIRECT_PROMPT.replace("Pending-CW outcomes are identified separately.\n", "")`：只去掉 pending-CW outcomes 一句，保留原 hybrid/free 计数说明，并非 `nocw_inputs.COMMON_PROMPT`。输入使用无损全候选/全已观测表，工程 validator 以 runner 实际覆盖入口为准。它不使用旧 query 协议的 24 query / 480 view 机制，也不提供 native tools。

原科学响应含 `packet_sha256`、`batch_strategy`、完整 32 个 `choices`（id、reason、hypothesis_id）、至多 8 个 hypotheses、`feedback_interpretation`、`batch_rationale`，以及原有 measured-evidence 约束。A/B/C 使用同一合法性、唯一性、packet 绑定、证据引用和科学协议验证器；非法响应先走共同工程纠错，不能被计作 C 的数值约束触发。

当前冻结运行的服务请求配置为 gpt-6.1-sol / xhigh；后续不得未经新授权替换模型、推理参数、provider 或预算。历史协议和后续传输恢复修订的实际重试上限、服务端模型回执、运行日期须另从被选状态清单冻结，不能仅凭原 PROTOCOL.md 推断最新有效传输配置。本研究不修改其 worker、恢复逻辑或资源调度。

## 3. 冻结状态、输入差异与权限

每个状态必须先有 manifest，包含来源、截止时间、文件原始 SHA256、split/初始化/预处理身份、数据 seed、预算、checkpoint SHA、有序 L/U、预测、同方法 raw/CW bank、候选分子和五条件、目标缩放、科学记忆、原 prompt/schema、服务配置和软件环境。不同来源状态禁止借用另一方法或 checkpoint 的 bank 补缺。

冻结差异检查同时检验内容和白名单路径：

1. A/B/C 的有序 L/U、候选行、原数值、QGeoGNN checkpoint、科学记忆、目标缩放、基础 prompt/schema 和共同工程校验完全一致。
2. A→B 仅允许 GP 侧车与解释增量；B→C 初始请求完全相同。C 后续仅允许追加已冻结数值反馈及对应 LLM 回答；原候选、记忆和 GP 侧车不能变更。
3. GP 侧车注明所用已观测集合、核/表示/噪声、拟合及校准状态、latent variance 与 predictive variance 区别、来源 checkpoint 与限制；未通过的信号不送入正式引导。
4. 拒绝未知字段、隐藏标签、test 字段、未来时点反馈、顺序错位、foreign checkpoint、NaN/Infinity；检查失败保留证据并停止该状态。

哈希是完整性检查，不能自行证明上游来源真实。真实适配器仍需核验已有 contract/batch freeze/bank metadata 的来源链。selector 和 controller 不获得 label-store、训练、模型推理、文件搜索或网络工具。

本次实际固定 seed157/6101 的初始 L333 bank，与新 CW-Free r00 的 checkpoint/hash/3330 行顺序映射对齐。响应 GP 用 L333 拟合，使用其后已经观测的 6 批、每 seed 192 点核验。风险目标为固定 r00 事前预测对这些已观测响应的误差：前 3 批 96 点拟合，后 3 批 96 点 forward 核验；不是训练内误差。原生逐轮 acquisition-time 误差的 checkpoint 差异另记，不混入该固定模型拟合。所有证据属于开发研究，固定 r00 风险不能作为后续 t 的当前 QGeoGNN 风险。

数值测试至少覆盖：float64；显式噪声；稳定 Cholesky 与 jitter 回执；重复/近重复特征；联合条件协方差；批次 log-determinant 信息增益；候选顺序不变性；白名单权限；freeze 差异；控制触发、豁免、修正、预算耗尽及不可判定。mock 不产生学习效果证据。

## 5. GP 放行与控制阈值预注册

正式进入 Phase 1 前，必须单独保存并哈希冻结 `phase1_manifest` 和控制器配置；本次原型/示例阈值仅用于 mock。需要依次满足：

1. **来源门槛**：所有监督在所检验预测时点已可见；校准/评价响应未参与相应表示和 GP 的拟合。若只有当前监督表示上的留出，明确标为回顾性证据，不能据此声称部署概率校准。
2. **数据门槛**：开发拟合、阈值校准、冻结可靠性核验集合分开，按 molecule/trajectory/checkpoint block 登记有效单位和样本数。样本不足或 block 太少时给不可判定，不以大量相关行制造置信度。
3. **概率门槛**：在冻结可靠性集合上，逐 V1/V2 报告 NLL、CRPS、80%/95% 预测区间覆盖及宽度，相对训练侧固定的常数均值/噪声预测分布作配对比较；核验不允许通过无限扩大区间换取覆盖。风险 GP 另报告合法误差目标上的排序、概率评分和状态迁移误差。输出均值好但覆盖差时只支持均值，不能放行已校准风险/方差。
4. **放行判定**：所需评分改善幅度、覆盖容差、block 数及不确定性区间必须在看冻结核验结果前登记。未登记即为未放行；不得事后设一组恰好通过的标准。Phase 0 的回顾性结果可用于提出这些标准，但不能兼作它们的确认数据。本次探索性筛查要求：两 seed、逐 endpoint 的响应 GP NLPD 均不差于历史 L0 Gaussian 基准，90% 区间覆盖率绝对偏差不超过 0.10；风险 GP 在各 seed 的 holdout rank rho 至少 0.2，且 Gaussian log-risk NLPD 优于历史常数基准；优化、数值与来源检查全部通过。任一失败即本次付费 Phase 1 为 NO-GO。这是本次小样本开发筛查的新门槛，不是外部确认或正式效能标准；即使通过也仍需登记适用 checkpoint/状态和后续冻结方案。
5. **阈值冻结**：在开发状态上校准条件信息增益下界、高相关冗余门槛、盲区定义与局部对照豁免；使用具有明确意义的参考分布/容差，不优化任意加权总分。冻结开发状态清单、候选参考批生成法、随机 seed、分位规则、噪声模型、阈值、豁免范围、反馈文本、数值容差及最大修正次数。正式状态只应用，不能重调。

信息增益必须来自条件于 L 的联合协方差。单独独立 GP 的一个示例定义为 `IG(B|L)=0.5*log det(I + R_B^(-1/2) Σ_(B|L) R_B^(-1/2))`；多输出独立假设下才可对已清楚定义的输出信息增益求和。不得将单点方差之和称为批次信息增益。具体实现以 [GP_METHOD.md](GP_METHOD.md) 为准。

## 6. Phase 1：同状态决策机制实验

### 最小候选设计

先选 **1 个 GP 可靠性适用、同方法 bank/来源完整的开发状态**，优先考虑与可靠性数据的 checkpoint 一致、机制边界最清楚的状态。若使用 seed157 的 L653 等已有非零历史反馈状态，必须另行建立当前 checkpoint 的 GP 可靠性；本次固定 r00 风险不能直接迁移过去。状态清单不得按预期 arm 效果或结果排名挑选；缺必要来源时按事前登记的可用性规则选替代并留下理由。之后才考虑另一个预算或 seed，不能默认扩为五 seed。

每状态先登记 3 个配对重复：每次 A 一份初始决策、B 一份初始决策，C 共享 B 原始合法提案并最多追加 **2 次数值修正请求**。因而在没有工程纠错和传输失败时最多 12 个完成响应；这只是未来预算方案，**本次未授权**。付费执行前需明确总完成响应、工程纠错、传输尝试、token/费用和时间上限；不能把 12 当作含所有失败的实际调用上限。

工程校验预算、传输预算三臂一致并逐项冻结。原 CW-Free 的 8 次答案尝试不能悄悄变为 C 的无限修正；新增数值请求额度独立计数，总硬上限须在授权预算中覆盖。任何 provider/config 不符、来源失败、模糊在途请求或硬预算耗尽均停止；不换模型或重采样直到获得有利批次。

### 随机性控制

对状态×重复进行预注册调用顺序随机化，A/B 在小时间块内交错；记录配置模型、实际 served model、provider、请求/响应 SHA、时间、token、缓存与费用覆盖率。provider 未暴露 seed/temperature 时标为不可控制，不虚构“同 LLM seed”。不把服务端稳定假定为事实。

科学记忆始终保持同一冻结快照，不将某个重复或 C 修正结果写回其他 arm。Phase 1 不揭示选中点新标签、不重训、不更新 L/U。每个重复独立启动上下文。

### 控制器事务

先运行共同工程 validator；通过后记录原提案及完整数值诊断。C 的结果为 `pass`、`revise`、`exempt`、`undetermined` 或 `failed`：

- `revise` 的反馈给出实际值、阈值、相关 ID/对、可复算定义及可接受的局部对照豁免，不提供 GP Top32 替代名单或固定比例。
- 豁免仅证明同分子且只有一个原始条件不同、其余四条件严格相同的结构，以及其关联的显式假设；不能由控制器判断化学假设真实。保护的对照可免于相应冗余限制，其余 batch 仍受未获豁免的约束。
- 无法可靠估计协方差/风险、分母退化或缺少来源时返回不可判定，不能自动视为通过。
- 两次数值修正后仍不满足条件则记失败；保留最后合法提案供分析，但不自动作为通过批次或进入后续标签揭示。

日志逐次保存原始响应/合法完整提案、输入/GP/config 哈希、诊断、触发规则、请求修正与否、豁免、最终选点、删增 ID、关联假设/理由变化、未解决项、成本和状态。记录“理由变化”来自实际回答文本，不由控制器编造科学解释。

### 预注册机制指标

| 指标族 | 定义与报告 |
| --- | --- |
| 选点重叠 | `|B_i∩B_j|/32` 与 Jaccard；跨 arm 及 arm 内重复分别报告 |
| GP 信息 | 已选点 posterior latent/predictive variance、合法 risk、单点条件增益的分布；整批联合 IG 单列 |
| 几何 | 当前同一 raw/CW bank 到 L 距离的分位分布、批内相关/近邻、remaining-U 覆盖，保留原尺度和零分母 |
| 分子/条件 | 分子数、同分子集中度、新分子比例、严格单因素对照数、涉及轴及完整 tuple 重复；不以更分散预设更好 |
| 控制机制 | 原始合法提案中的触发率、规则分解、豁免率、请求修正率、最终失败/不可判定率；修正前后配对 IG/冗余/对照变化 |
| 稳定性 | arm 内重复的两两 Jaccard 与数值诊断 SD/IQR；少量重复仅作描述，不等同跨种子学习稳定性 |
| 可靠性与成本 | 首次/最终工程合法率、工程与数值纠错分别计数、传输失败、全部请求/token/等待、费用缺失覆盖率 |

C 的 IG 升高是约束可能直接造成的机制结果，不能循环地当作学习成功。B/C 额外反馈包含数值内容与更多思考机会；只有三臂不能完全识别二者贡献。成本必须完整报告；如需区分，后续另行预注册“相同请求数的中性复核”敏感性对照，不在本次自动增设 arm。

### Phase 1 → Phase 2 门槛

必须来源/输入差异校验全部通过、GP 可靠性已放行、日志完整，且控制器至少在一个冻结测试状态产生可解释的真实触发/修正或明确证明该规则在这些状态不触发。若全不触发，先报告机制未识别，不自动扩大训练。最终无未解决的安全性来源问题、完整 32 点决定可复算，触发/豁免不是只重复合法 ID 规则；不得依据哪个 arm 的诊断“看起来最优”删状态。

允许据此提出有限短程实验；少量 Phase 1 决策不能证明性能提升，也不自动授权 Phase 2。

## 7. Phase 2：有限同状态短程学习

另行授权后建议采用 **2 个事前指定开发 seed、各 1 个同预算 anchor、A/B/C 各 2 批 B32**，先完成所有第一批 freeze 再按共同训练协议推进。初始 anchor 的 checkpoint/L/U/记忆/初始化/预处理/训练规则完全相同；分支后第二轮 checkpoint/L/U 将自然不同，不再称第二轮为相同输入。

相同 scratch initialization、shuffle/RNG 协议、optimizer、epochs/patience、validation checkpoint 规则、L333 目标尺度。训练失败按共同冻结策略处理，不能只为某 arm 更换随机状态。若研究训练随机性，必须事前另加独立 training-seed 因子并对三臂配对；不把 acquisition seed 与 training seed 混为一项。

只揭示各分支已冻结的 32 点，不读取另一分支未来 outcomes。主指标为 validation NRMSE 改善、短程 AULC、V1/V2 分项误差及 seed 方向。当前 validation 已用于 checkpoint 选择，结果属于开发诊断，不能冒称独立泛化确认。

对预算 n、n+32、n+64，短程归一化梯形 AULC 为 `(E_n+2E_(n+32)+E_(n+64))/4`；使用原始非单调误差，不用 best-so-far。报告 B−A、C−B、C−A 的逐 seed 配对差，不能只报告赢家。

**建议预注册的 Phase 2 → Phase 3 预算继续门槛**：C 相对 A 的两 seed 短程 AULC 均下降，平均相对下降至少 2%；两目标在终点的平均误差均无超过 2% 的劣化；C 相对 B 的平均短程 AULC 不升；没有未解释的失败或成本超限。这是小规模继续投入的实用门槛，不是统计显著性或性能保证；2% 沿用仓库既有探索性门槛量级，不是 GP 目标权重，也未用本次结果调优。正式执行前可根据已登记的训练重复性噪声重新提出一次门槛，但必须在该阶段结果出现前冻结，之后不得回调。

若没有通过，报告负结果或不可判定并停止；不得通过追加有利种子、改窗口、换主指标、提高修正额度或调控制阈值自动放行。

## 8. Phase 3：正式多种子验证的预备要求

冻结 A/B/C 的全部方法、来源、prompt、阈值、GP 拟合/校准策略、控制预算和分析代码后，登记确认 cohort、样本量/精度依据和唯一主预算窗口。不得自动扩大到 L1485。历史开发 seed 独立列报；如使用新 data seed，明确其与旧划分的重叠和同源数据局限，不能称为新外部确认集。

主指标包括平均 AULC、跨数据 seed 的 AULC 标准差、高分位与最差 AULC、达到预注册固定误差阈值的标签预算，以及无效响应、纠错请求与总成本。少种子时高分位估计不稳，同时报告原始逐 seed 和最大值；同一 seed 内轮次及 LLM 重复不是新的独立 seed。

采用共同预算网格 `b_0…b_T`，`AULC=Σ[(b_(t+1)−b_t)(E_t+E_(t+1))/2]/(b_T−b_0)`。越低越好。固定误差阈值先在开发阶段确定，正式阶段报告首个实测 crossing、首次达到并保持到终点的预算，以及未达到的右删失；不做窗口外外推。

主比较 A/C；A/B 与 B/C 为机制分解且一起报告。LCMD/Numerical Hybrid 等独立数值强基线使用同预算和相同误差口径，来源不匹配则单列。区分 data seed、LLM 重复、training seed、provider/served-model 时间块；说明依赖结构，禁止把所有轮次当独立样本。正式 test 处理若将来需要，必须另行授权并有全局事前 freeze；本次不访问 test 真值。
