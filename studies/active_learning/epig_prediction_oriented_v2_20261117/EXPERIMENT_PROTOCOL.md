# EPIG v2 exploratory development protocol

This is a **post-stage1/stage2 exploratory development study** on an extensively reused historical cohort. It does not amend or retroactively satisfy either original qualification gate. Original source commit is `f27c1bbca2296ea6ac38b713cc9ec1eec8153be4`. The original study, including both freezes and all results, is protected by `evidence/initial_inventory.json`. New decision code lives here because the old freeze binds the shared source tree.

## Timing and distinct evidence

The existing Stage 1/2 outcomes, old acquisition diagnostics, and historical QGeoGNN results were known at design time. This protocol precedes new v2 acquisitions and training. Mathematical/reference and surrogate investigations additionally write their own immutable protocol/hash receipts before computing new outcomes; these diagnostics are exploratory and cannot choose a different primary surrogate after seeing their results. A code fix requires preserved evidence, a new versioned freeze, and an explicit indication of which trajectories remain comparable.

The paper defines EPIG as expected information about a randomly drawn target label, and distinguishes it from information about parameters. Its Gaussian case motivates our closed form; transferring any resulting surrogate objective advantage to QGeoGNN requires actual learning curves. [Bickford Smith et al., AISTATS 2023, §§2.3, 4, Appendix E](https://proceedings.mlr.press/v206/bickfordsmith23a/bickfordsmith23a.pdf).

## A/B: numerical correctness and reference integration

Keep latent cross covariance and observation-noisy marginals. A target at the same X as a selected candidate denotes a separate future noisy replicate. The batch objective is the average **per-target** `I(Y_target; Y_batch | L)`, not `I(Y_all_targets; Y_batch | L)`. Use a dense Gaussian Schur oracle on small independently generated single/multi-output matrices, several noise/correlation regimes, near-singular legal boundaries, invertible output transforms, repeated X with independent noise, ID reordering, cache/chunk changes, and batch chain rule. Preserve old passing tests; add only meaningful tests for new behavior.

Hold the posterior literally fixed in offline objective comparisons. Add BALD `0.5[logdet(K_xx+R_x)-logdet(R_x)]` and conditional batch BALD. Compare single-point scores, Top32, conditional greedy B32, overlap, and all selected batches evaluated with the same per-target batch MI. BALD has no target-distribution integral; its independence from M/P1/P2 is an expected control.

Use all 3330 outer-training X for P1 and all legal current U X for P2. Covariance requests are bounded chunks; do not materialize a complete U×U matrix. A disk-backed target/candidate cache may store bounded blocks and apply batch rank updates. Record cache bytes, process peak RSS, elapsed and active time. Use a shared SHA256 order depending on seed and row ID but excluding distribution, so common rows have the same relative order. Compare legacy independently salted M256/1024/2048, coupled M256/1024/2048, and exact finite-population integration. Report score error, Spearman, Top32 overlap, greedy batch overlap, and MI on full targets. These analyses use only original L333-trained frozen posteriors, inputs, and label-free covariance updates.

## C/D: bounded proxy development, separate from primary efficacy

Freeze at most 60 new honest OOF model fits / 30 active minutes, all five seeds and three folds, in `surrogate_protocol.json`. F0 is the old 29 coordinates; F1 separately preserves density and sample volume as well as their product; F2 treats molecular/condition groups explicitly and compares full coordinates with PCA16. A fixed enhanced-optimization arm allows comparison with the old 60-iteration/one-start cache. Standardization, PCA, output scaling, mean/noise fitting use only each training fold. Do not select features from U labels. Report convergence, parameters, likelihood, retained directions, NLL, 80/95 coverage, residual shape/tail concentration, calibration by inputs/molecules/predictive SD, full/block/diagonal NLPD, conditional logscore, covariance validity, and acquisition sensitivity where actually computed.

Mean, ARD, heteroscedastic and robust likelihood alternatives are audits/feasibility questions unless their implementation and budget are separately frozen before results. No unimplemented family counts as tested. A non-Gaussian likelihood needs a newly verified MI estimator. A covariance temperature transform `DΣD` applied consistently does not change same-posterior EPIG. No global-temperature search is authorized as a ranking fix. The original hard thresholds and failures remain unchanged; report counts, distance to threshold and finite-sample sensitivity alongside any diagnostic uncertainty interval.

A GNN representation trained on all L333 is label-dependent for held-out L333. Such representations may be used only as explicitly conditional diagnostics; honest OOF requires training-side encoder cross-fitting, or a genuinely label-free representation. Quantiles are never cross-input covariance. This direction cannot replace the primary predictor.

## E: primary actual QGeoGNN learning comparison

All seeds `157,887,2357,6101,12203`, both arms, 21 B32 acquisitions from L333 to L1005; target **210 successful subsequent fits**. Reuse each seed's verified historical L333 checkpoint. Each subsequent fit uses the unchanged 458952-parameter QGeoGNN-V2, original Row split (3330 outer train, 416 validation, 417 test), original graph/feature normalization, fixed L333 V1/V2 scales, same per-seed initialization and training RNG, Adam 0.001, zero weight decay, batch2048, maximum1000 epochs, patience100, scratch training, validation combined NRMSE checkpoint selection. No test labels are evaluated. Pass legal U explicitly as prediction indices to avoid the generic context's default test-X route.

Both arms use F0 Matérn-3/2 independent-output empirical-Bayes GP, PCA≤16, maxiter60, one start, current-L constant mean, fixed L333 endpoint normalization followed by training-side GP internal output scales, homoscedastic endpoint noise, refit on that arm's legally revealed L at each round. These are the same **modeling rules**; after trajectories diverge the fitted posteriors differ. Within a state only the EPIG versus IVR objective changes. Original Matérn qualification is not satisfied for all seeds; this fact is carried into every result. We choose a single fixed model rule to isolate the objective and do not select it using new learning results.

Primary target is exact P1 integration over all outer-training inputs with independent future target noise. Use conditional greedy B32 in both arms. IVR is absolute predictive variance reduction in fixed-L333-standardized endpoint units, as in the original formal callback (`run_study.py:303–304`). The GP is fitted to `y/[L333_std_V1,L333_std_V2]`; its own internal current-L scales are then consistently propagated into covariance/noise in these normalized units. Physical-unit MAE/RMSE reporting is separate. IVR endpoint weighting differs from EPIG and is disclosed. Offline BALD must complete; no third training arm consumes EPIG/IVR resources.

Before every label reveal, validate exactly32 unique current-U IDs, persist immutable selection with X/model/L/U identities and its byte SHA, then authorize only the selected labels. The callback receives only outer X and current-L y; it receives neither validation nor test targets. Persist every label-access receipt, including access that precedes a failed fit, and fail closed on protocol/hash drift. Successful caches require all file hashes, input identity and exact acquired truth equality. Interrupted scratch fits are archived, never overwritten or warm-started.

## Resources, failures and resume

The local preflight found 24GiB RAM, 10 CPUs, ~199GiB free disk and no active training; old low-CPU monitors are left alone. Historical five-seed one-arm 21-round fits cost15.66h; a two-arm extrapolation is31.32h, not a completion guarantee. Use one QGeoGNN worker and two threads. Reserve 72 cumulative active QGeoGNN hours and 12 auxiliary hours (84 total); inactivity while stopped does not count. Bound neural attempts at231 (210 successes plus21 extras), at most3 attempts per fit key. Bound auxiliary attempts at330 for at most300 successful fits (210 current-state fits, ≤60 OOF fits, ≤30 feasibility/resumption fits). Reference diagnostics have a2h active subcap. Each individual operation has a4h active timeout; at most3 attempts per key and at most22 supervisor process launches. The supervisor restarts only explicit transient I/O/interruption errors; scientific/numerical failures require audit. No unlimited retry loop. Every failed/interrupted attempt records type, reason, elapsed time and retained directory. Activity tracking includes failed attempts, with a2s durable heartbeat; process-death recovery charges the last heartbeat plus one interval and excludes subsequent downtime. Offline diagnostics reserve65 auxiliary fits/attempts and2.5h (upper bounds, separately labeled from actual measured consumption), leaving callback235 successes/265 attempts/9.5h. A missing process is not an efficacy stop.

Only numerical invalidity, label-access errors, unrecoverable protocol drift, unavailable resources or explicit resource caps can pause. Poor early curves, overlap with IVR, calibration failure, low proxy MI and early AULC loss cannot stop a trajectory. A pause/incomplete result must remain incomplete. The original absolute40h/210-attempt policy stays untouched.

## F: reporting and decision

Primary endpoint: paired validation combined NRMSE trapezoid AULC over L333–L1005, divided by672, using original **nonmonotone** curves. Report all five seed curves, V1/V2 row MAE/RMSE in ml, L525/L813/L1005, early333–525/middle525–813/late813–1005 AULC, terminal tradeoffs, per-seed EPIG−IVR, cost and failures. Never fill missing budgets, use best-so-far envelopes, or call an incomplete trajectory a negative result. Five overlapping outer seeds are the inferential units; seed SD and paired effects are descriptive. Any t4 interval/permutation is explicitly limited by overlap; rows/folds/rounds are not independent replications.

Historical Random/LCMD/Kernel-IVR/Numerical Hybrid/Free LLM curves are retained read-only and strictly compared only after verifying predictor, split, initial state/scales, scratch protocol, checkpoint metric, budgets and label boundaries. Existing baseline inventory is evidence, not blanket certification.

Mechanisms: objective-only at common state; pointwise versus conditional batch true MI; P1/P2 with coupled sampling/full integration; surrogate versus GNN prediction/error structure; input-matched sample/loading-solvent volume and PE/EA response. True one-step utility needs immutable legal counterfactual branches and authorized selected labels; no future-U oracle. Numerical ranking or proxy MI does not establish real learning benefit or causal failure attribution.

After all210 primary successes, preserve the complete window. If full AULC, terminal, late AULC or reproducible seed/budget heterogeneity warrants extension, freeze a new paired L1485 protocol and finite resource budget before any extension; neither method may extend alone. Lack of L1005 improvement cannot establish long-run EPIG failure. Free LLM use requires real efficacy evidence and reliable incremental numerical guidance; no paid LLM calls are made here.
