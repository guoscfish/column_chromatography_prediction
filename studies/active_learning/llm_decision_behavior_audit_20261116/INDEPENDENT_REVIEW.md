# 独立代码与数值复核

复核对象为本目录 `collect.py`、`analyze.py`、`metrics.py`、`performance.py`，另交叉审阅选择偏好与Hybrid来源逻辑。复核没有训练、调用LLM或查询真实标签。以下将源码审阅、数值抽核与统计解释分开，不把抽核通过等同于全部科学假设成立。

## 已核对的数据时间与身份

- 旧综合诊断只读封存检查通过：4587个输入、122个输出hash匹配。
- `states.json.xz`有791个实际接受批次、25312个选择事件；813个保存评价点组成22条campaign。
- 对全部791个状态逐组检查，相邻历史均满足 `H_(t+1)=H_t∪B_t`，无重复已测行购买；选中行均在实际U中。根脚本也已加入逐轮累计历史assert，防止增量最近邻更新掩盖状态错配。
- 实际复用的旧metadata字段仅为id、smiles、conditions；partition只有身份、canonical_index、role和seed。候选预测/梯度来自各自冻结状态，验证指标仅用于事后性能关联；没有以候选未来标签计算选前行为特征。
- Row split的test身份/无标签结构元数据不是test truth；本次没有读取test响应或test预测行。全域4162行结构/条件元数据用于共享距离尺度，每seed实际初始合法域为3330行，这一区别必须在方法中保留。

## 独立数值抽核

以每组seed157的r0为抽样状态，直接由原始元数据的Fraction/Decimal语义、显式逐因素比较、Counter平滑、Morgan指纹距离和固定128参考点重算；未调用被测 `describe_batch` 函数。

|---|---:|---:|---:|
| CW-gradient LCMD32 | 0.265625 | 0.00950937 | 0.01105707 |
| 16＋16 | 0.27604167 | 0.01321451 | 0.01584476 |
| Historical CW-Free32 | 0.27604167 | 0.00836527 | 0.01909425 |
| New CW-Free32 | 0.22395833 | 0.01300081 | 0.00996429 |

与输出表最大差为3.34×10⁻⁸，来自float32距离存储。以上仅为算术测试，不能将一个初始批次当作整条轨迹的效果结论。五组相同初始状态下，固定500批无放回随机选择的Hamming均值均为0.24011458，与表差3.34×10⁻⁹。Coverage随机数组的参考点×重复×batch三个维度、先min后mean的顺序也已审阅正确。

对813个评价点检查各campaign的32步标签网格完整。独立使用Decimal半端点权重重算CW-LCMD五seed与NoCW五seed共十条L333–1485原始AULC，与11月16日已封存最终报告最大差1.67×10⁻¹⁶。该计算保留原始上升/下降点，未使用累计最优。

## 审阅发现并推动修正的问题

| 问题 | 原影响 | 修正与状态 |
|---|---|---|
| NumPy2.4.6已无`np.trapz` | AULC导出会执行失败 | 改为显式梯形和，不依赖已移除API |
| Rarity只输出raw surprisal | 用户公式可满足，但与论文原式归一化不完全相同 | 增加`rarity_paper_normalized`，raw继续保留 |
| Rarity类别数使用跨seed全metadata域 | 绝对Rarity中包含本seed不可选类别的先验质量 | 类别数改为各seed固定初始L0∪U0支持域；距离尺度继续使用明确标注的共享无标签元数据 |
| 全域标签编码与seed内类别数长度不同 | 个别分箱状态会发生bincount索引越界 | bincount数组长度覆盖全域最大code，概率分母仍采用seed域类别数，并增加边界单测 |
| 最近邻缓存只增量更新、未在循环显式核对累计历史 | 上游若错配状态，可能被悄然带入后续距离 | 增加每轮实际H与累计H一致性assert；全部真实历史独立核验通过 |
| 固定条件尺度回执仅保存标准化后0/1 | 数值范围不够直观复核 | 将原始minimum/span显式保存到验证回执 |

修正后的最终输出复核状态以本文末附记为准，不能把修正前的旧PASS回执当成新版执行结果。

## 科学与统计解释边界

- 所有距离/结构表示是无标签固定表示，原始gradient仅在对应checkpoint状态内解释；没有跨轮把变化的向量当固定坐标。
- 每状态随机基准满足真实U、无放回32和已测排除。它是行合法性基准，不保证随机生成可通过科学文本schema，也不是另一条策略rollout。
- 主条件距离是四个连续因素min–max归一化后L1加一个溶剂类别失配、再除以5；不能将其当物理定律。RMS敏感性、新颖性分箱与固定指纹提供替代视角。
- Hybrid来源以pending IDs与LLM choices并集验证；从全批行序猜来源的风险得到规避。联合覆盖的顺序平均归因是几何量，不是学习性能贡献。
- 性能关联以batch为单位，控制标签预算、当前损失、策略，并在seed内计算后汇总；没有把候选行当独立重复。seed bootstrap为当前2/5个seed块的描述性重加权，不是总体强显著性证据。
- `five_seed_all_methods`这一程序scope名表示所有可用方法合并后的五个seed块；其中Hybrid仍只有两seed，不能写成五组各有五seed。
- 行动条件Logit的正例也进入softmax分母；负样本排除整批实际已选。逐点近似不恢复LCMD的批内集合依赖。q90−q10不等同于已校准贝叶斯认知不确定性。
- 无高价值历史样本的事前定义时不构造该距离；无跨轮一致概率信念时不解释M/Z；无去历史消融时不宣称context文本的因果作用。多个指标/阶段的相关性均是探索性描述。

## 最终输出复核附记

最终第四次离线重算已生成新的791批输出及验证回执。复核确认：Rarity采用各seed初始3330行支持域，新增论文归一化列；固定条件原始minimum/span已明确保存；bincount全域编码边界修正已写入源码及单元测试。

在22条campaign各抽r0/r10/r20/r34共88个状态，独立用Counter与标量`math.log`重算raw和论文归一化Rarity，与最终表最大差4.45×10⁻¹⁶。此前验证的距离、coverage和随机计算未因该修正改变。独立运行 `python -B -m pytest .../tests -q -p no:cacheprovider`，**18项测试全部通过**，包括来源去重、距离、Rarity平滑/边界、覆盖单调性、随机抽样、标签horizon、非单调AULC和Logit稳定性。

当前复核结论为 **PASS_WITH_SCIENTIFIC_LIMITATIONS**：未发现剩余阻断性数值/身份错误；候选状态完整性、观察性混杂、五seed小样本和代理量科学解释仍须随报告保留。这里的PASS不证明算法优劣的因果机制或未来实验收益。
