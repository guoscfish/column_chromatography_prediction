# 论文方法与本项目迁移边界

来源为 Akke 等《LLM sequential decision making under uncertainty in biochemical domains》，[arXiv HTML v1](https://arxiv.org/html/2609.33061)，重点核读Methods4.10–4.14、Figure3–4及Section2.5。以下将论文定义与本项目可识别量分开；论文在其他领域的经验结论不作为本色谱数据的证据。

| 原方法 | 核读结果 | 本项目适用性 |
|---|---|---|
| 4.11 V/U | 共同GP提供共享z标准化的均值/标准差；ridge λ=1；每选择64个均匀负候选并排除整批已选；whole-campaign bootstrap；批内各选择被视为独立近似 | 色谱目标是降低行级预测损失，保留量均值不能作为实验价值。没有决策前候选学习价值预测，不能同义复现V；用G/U_proxy/D/C拟合的是项目行为系数 |
| 4.12 Novelty | 到选前历史的最小Hamming距离除以因素数，再按批平均 | 可复现离散代理；连续条件另用固定数值尺度，分子结构与条件分开 |
| 4.12 Rarity | 全历史计数加一平滑；负对数惊讶度再除以log(history size＋该因素类别数) | 同时报用户要求的raw surprisal与论文归一化版本；计数不能包含当前批 |
| 4.12 Coverage | 触达过的各因素类别数占总类别数的增量 | 可实现；分子—条件状态/几何覆盖是本项目扩展，须另命名 |
| 4.12 随机校正 | 在同一历史下对剩余池均匀选择，报告超出随机的量 | 每实际状态单独抽样，遵守合法排除；不使用全局统一随机分布 |
| 4.13 意图 | 使用外部Judge从reasoning trace估计探索比例并验证 | 本任务禁止Judge；透明词典/规则仅筛查stated rationale，不能等价恢复完整推理 |
| 4.10 信念 | 可比概率信念与测量噪声修正是M/Z解释的前提 | 只有理由/行动频率时仅称Action Preference Dynamics，不计算或解释为校准后的信念过度反应 |
| 2.5/4.14 上下文 | 去历史但保留工具的消融还涉及工具过滤权限，论文以2×2检验 | 本项目没有配对去历史实验；邻近行为只能支持“与context-stickiness相容”的描述，不识别历史文本的因果作用 |

条件Logit使用数值稳定的完整choice-set softmax：正例也包含于归一化分母；HTML Eq.10显示的`y≠x`不应被照抄成排除正例的非法概率。共享标准化规则使策略系数可比，但无法解决G与D/C的共线性或当前状态漂移；先单/双特征，覆盖率或秩不足时只报分位。LCMD是集合算法，逐点Logit不精确建模其批内更新。

`G`建议定义为已缓存的CW最近L距离/排名，而非“真实信息量”；`D`用固定结构或条件新颖性；`U_proxy`明确为单预测器q90−q10宽度，不能叫已校准的epistemic std；`C`用相同固定参考集的边际覆盖。ensemble disagreement或GP posterior std只有存在可审核缓存时才另列。本任务不新拟合GP来制造原论文的Value轴。

Hamming、Rarity、Coverage都是探索代理，既不等于信息增益，也不保证下一轮损失下降。原论文围绕高适应度候选的best-so-far任务；本项目最终主要结果为原始非单调validation Row NRMSE/AULC（越低越好）。适用性差异必须先于任何“论文复现”结论。

方法稳健性分别需要：连续因素分箱敏感性、距离尺度敏感性、同状态随机抽样稳定性、负采样重抽样、whole-campaign重抽样与候选完整率。双seed bootstrap只能显示当前两条轨迹的重加权波动，不能变成总体精确置信区间；多个指标/阶段的探索性关联必须注明多重比较。
