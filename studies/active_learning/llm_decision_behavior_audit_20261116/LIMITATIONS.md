# 证据边界与不可识别因素

- 原论文以优化fitness为目标，本项目以Row预测损失为目标。不存在同义的候选Value估计；G/U/D/C是项目特化行为代理，不能冒称严格V/U复现。
- 实际行为791批、22条轨迹；四纯策略各5seed，Hybrid仅2seed。独立化学数据集仍只有当前4g数据，outer row splits重叠；25,312选点行不是25,312个科研重复。
- L333同seed初始checkpoint/L/U一致，随后各自历史与预测模型分叉。不同策略同预算不等于冻结状态反事实。Historical及Hybrid有Astra/high前缀和Sol/xhigh续跑；同声明模型也未控制后台路由、日期、Prompt记忆及重试。
- NoCW去掉显式CW，仍有预测分位、宽度、化学描述、历史反馈与解释记忆。它不能代表没有数值信息，也不能和混合模型Historical直接构成纯CW因果消融。
- U_proxy在611个LLM/Hybrid状态可算，纯CW数值180状态缺同类catalog，保持缺失。G在Historical/New/Hybrid共431状态复用完整catalog；NoCW及纯CW分别仅核心两seed42状态从可信缓存补算。其余G是本次审计范围未展开，不能写成缓存一定不存在。条件Logit的部分覆盖模型只解释其实际子集。
- G是当前CW表示的最近历史距离，C是静态单点覆盖；均不等于真实LCMD逐步集合效用。数值LCMD本来就优化自身几何，较高G不能自动视作更高行级信息收益。
- Hamming把连续非零改变量离散化；已补连续L1/RMS与固定分箱敏感性。无流速等未记录因素；density常随分子固定，不当成独立实验操纵。共享尺度来自4162行无标签元数据，每seedRarity域与随机池则严格限其初始/当轮合法域。
- 全部分子可能很早已被覆盖，累计分子与结构最近距离出现饱和；接近零不等于后续条件实验无价值。未知高价值历史集合没有事先定义，未事后挑选。
- 500次随机基线复制行身份、预算与排除规则，不复制科学理由schema、LLM纠错或LCMD生成机制。Hybrid条件随机只检验补充几何，不等于随机化学习性能。
- 文本611批仅最终stated rationale，不是完整内部思维。关键词可能漏掉同义表达或命中否定句；原文可复核，相关不作为意图校准分数。案例按边界规则选择，不估计总体发生率。
- 没有可比多轮信念概率与测量噪声估计；只做Action Preference Dynamics，不给Martingale/Excess Movement结论。没有同状态ensemble disagreement；没有新增GP拟合来填补此缺口。
- Row性能来自既有开发validation，并已用于checkpoint选择；不是test性能。没有读取test truth、未来标签、未测候选结果或重新查询真值。未用test反向选特征。
- 行为—gain关系受状态路径、策略、配置、当前损失及阶段混杂；gain与e_t的算术耦合、回归均值与跨轮相关仍在。seed块bootstrap只有2/5块，100次偏好bootstrap与多指标扫描均为探索性，不作强显著性或因果宣称。
- Hybrid两来源顺序平均的覆盖归因不是学习收益归因；没有保留/移除半批后的配对重训，不能认定协同、互相替代或精确收益贡献。
- 未安装Parquet引擎时，逐候选指标以无损CSV交付并显式记录。没有为输出格式安装依赖或触发任何付费服务。
- 原始文件与旧封存不改写。旧封存报告曾披露其此前会话的一次标签检索事件；本次复用不含标签的快照/表，并不将旧会话的偏差冒充本次数据流。本次新的脚本不打开标签真值文件。

这些限制允许比较历史行为与真实已保存性能，允许提出可证伪机制；不足以决定任何数值辅助策略必然有效。
