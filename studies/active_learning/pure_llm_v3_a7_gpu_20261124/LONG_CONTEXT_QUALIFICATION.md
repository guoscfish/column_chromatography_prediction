## 4. 推荐格式及实际请求片段

建议采用 `a7_grouped_tables_v1`，启用三位小数、显式宽度与交叉保护。每组保留分子身份及可直接读取的行表。公共条件因子化后，表头仍明确给出顺序、单位、恢复规则和字段含义。宽度显式展示，便于模型比较，无需从分位数反复计算。2 位小数没有额外的 token 收益，并增大相似度离散误差。全局完整条件元组字典因几乎每行都不同而增加负载。
