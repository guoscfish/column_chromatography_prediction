### 数字、重复项与空字段

- 全请求有 35,506 个 JSON 浮点数，原数字串长度范围 3–20 个字符，P50 为 17、P90 为 18、P99 为 20。分位数字符串的列中位数为 17–18，两列宽度均为 17。两列实测标签分别为 17 和 18。`EA_fraction` 的中位数为 18。以字符串保留的原实验条件不纳入该浮点统计。
- 3,330 行只有 19 个完整条件元组重复组，共 3,311 个不同元组。字段因子化的空间更大，例如 PE/EA 10 种、流速 5 种、上样溶剂 3 种、上样体积 8 种。旧格式已全局存储 `column_specs`，并将 224 个试剂元组独立存储。
- 六分位数中的 q50 别名已经省略。V1/V2 的宽度在所有 2,997 个候选中都满足按发送方浮点运算重构 `q90-q10` 后数值序列化相同。3,330 行的 `loading_amount_mg` 均可从原密度和样品体积重算。两个宽度的显式可见性仍有模型易读性价值。
- 候选的 `max_similarity_to_observed` 只有 38 个不同值。分子新颖性和条件新颖性各有两个不同值。空项为 48 个分子分组的空 `observed` 表、M2 内三个空数组和一个空字符串，以及试剂表内一个 `null` 单元格。

## 后期上下文合成估算

固定 seed 157 的已发送条件、分子和候选预测，从该池以固定种子打乱并每轮移动 32 行。给移动后的行补入虚构观测值和相应的历史预测、残差，保持原始行身份和完整条件表。M2 模拟每轮 32 条最新反馈，分别测试每轮 0、2、8 个新增假设，每个假设 8 个观测引用并按固定比例归档。中等和压力情景都用固定的简短虚构文本。该工件只模拟布局容量，未读取或生成任何真实新增标签、预测或选点。第 36 阶段的 L1485 仅作终点容量检查，正式轨迹的最后一条请求在 L1453。

紧凑列采用推荐的 3 位小数格式，显式保留宽度。若舍入会掩盖已有分位数交叉，整组分位数保持原精度。转为观测的每行少了六列分位数及两列宽度，历史预测和残差列、最新反馈和持续积累的假设会增加负载。压力情景下，紧凑格式的 L1453 比首轮约多 5.7 万 proxy token。运行路径、记忆文本长度和后续预测可能改变实际体量。

## 本地复核

使用本地校验过的 `o200k_base` vocab 缓存。审计脚本拒绝从网络隐式补齐缺失词表。`REQUEST_ARCHIVE` 指向本机私密 job，不需要导出请求内容。

```bash
study=studies/active_learning/pure_llm_v3_a7_gpu_20261124
python -m studies.active_learning.pure_llm_v3_a7_gpu_20261124.offline_context_audit \
  "$REQUEST_ARCHIVE" --tokenizer-cache "$TOKENIZER_CACHE" \
  --five-seed-preflight "$study/remote_cuda_with_sdk_20261125.json" --compare-compact
```

输出仅包含摘要、长度分布、请求标识和内容 SHA。 [离线审计实现](offline_context_audit.py)
