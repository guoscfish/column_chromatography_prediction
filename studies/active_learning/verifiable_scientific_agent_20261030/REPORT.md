# 科学实验 Agent：历史可靠性审计与最小可验证规划原型

2026-10-30。**存在跨方法反复出现、具有实际请求和人工介入代价的合法性问题，足以支持优先修复 Level 1；尚不足以证明复杂新 Agent 或 Numerical Critic 会改善学习效率。** 主要瓶颈是候选身份定位与观测证据归属，以及独立存在的传输问题。仅修 JSON 格式不能解决本次主要失败。

本次已完成历史审计、独立细粒度诊断、局部修复 mock、稳定候选索引和 Numerical Critic 静态接口。没有新增真实 LLM 调用、训练、标签揭示或 test 读取，也没有改动 NoCW worker 或冻结版 validator。完成后停止，不自动启动下一轮实验。

## 3. 纠错改变了什么

114个纠错轮的首提案均可可靠比较；其他中间响应若schema混乱则不构建确定批次。现有协议每次都要求完整重新提交方案。

| 方法 | 纠错轮 | 最终ID集合改变 | 首提案合法ID全部未保留 | 保留的合法ID / 首提案合法ID | 保留ID中理由逐字不变 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Free | 68 | 63 | 12 | 988 / 2007 | 174 |
| Hybrid | 20 | 14 | 1 | 206 / 294 | 50 |
| NoCW | 26 | 21 | 8 | 309 / 794 | 68 |

这支持“整批纠错经常改变原来已经合法的选择”，但**不证明改变有害，也不证明文字相同就保留科学意图**。原始非法ID无可靠元数据，因此首提案行为指标只覆盖合法子集；它与最终完整方案分母不同。分子集中有增有减，不能把局部子集与完整32点的差值当纠错因果效应。

补充几何核验读取了已有冻结bank，114纠错轮中111轮可按同checkpoint和有序L/U核实：Free68/68、Hybrid20/20、NoCW23/26。缺失的是NoCW2357/6101/12203的r0；不借其他方法的bank补齐。raw主LLM组件中，批内NN距离/到L距离的比值下降分别45/68、11/20、16/23轮；但“批内NN距离小于到L距离一半”的点比例上升/下降/不变分别为Free7/26/35、Hybrid3/1/16、NoCW2/8/13，有效秩上升50/68、9/20、13/23轮。指标方向混合，且首提案合法子集往往比最终方案少，新增点本身会改变最近邻和秩，**没有证据可把纠错概括为系统性增加几何冗余**。raw/CW逐轮分开，同状态描述不作为跨轮绝对距离或学习收益比较。Hybrid另提供pending+LLM全批视图，与主LLM16视图分开。详见[几何补充说明](REPAIR_GEOMETRY_NOTES.md)与[逐轮几何表](repair_geometry_profiles.csv)；原始主审计CSV中的几何NA保留，并通过此独立表补充，不重写冻结统计。

用户指定病例NoCW2357/r10：第1答案32项、30个合法唯一候选、2个未知ID；第2答案32项、31个合法候选、1个未知ID；第3答案把hypothesis形状对象混入choices，37个元素且缺少顶层hypotheses，**原始计划不可分析**，不能抽出前32项宣布恢复。追加授权后第4答案合法冻结。该例验证的是定位与结构失败及额度耗尽，不能写成已证实重复ID。

该轮也有可直接核验的设计内容变化：最终32个ID与最初30个合法ID完全无交集；首答专门提出m125加载溶剂体积与流动相比例交互的 `H_volume`，最终假设表没有该命题，最终rationale加强普通中性芳香区的anchors。首答合法子集为21种分子/30点，最终为29种/32点；同时carbonyl条件响应、不能统一修正polar tail等宽泛假设仍保留。可说具体实验和部分科学问题改变了，不能说所有意图丢失，或据此判定最终方案更差。首答还明确解释一个同条件重复为再现性问题，说明“条件重复”本身不能自动判错。

逐轮保留、删除、增加、理由变化、条件覆盖与分母见[repair_trajectory_analysis.csv](repair_trajectory_analysis.csv)。语义证据的人工病例另见[SCIENTIFIC_ISSUE_REVIEW.md](SCIENTIFIC_ISSUE_REVIEW.md)：未知引用有明确排除、含混措辞及无法追溯的anchor三种情形，不能一律称幻觉。

## 4. 离线原型与A/B/C结果

独立实现 `verifiable_planner.py`，不修改生产validator：

1. **细诊断**：原合法性判定不变，同时列出具体ID、位置、缺口、schema路径和非法证据关系。
2. **局部修复请求**：锁定合法选择；非法slot由LLM显式重写实验ID和理由，证据错误要求显式重写受影响hypothesis。没有清晰科学意图时要求完整重规划。只提供unsent协议与mock，没有真实请求。
3. **稳定索引**：按完整原候选顺序建立一对一短编号，保留所有原信息列，绑定packet与映射；不排序、不筛点、不增加CW配额或loading cap。真实LLM的位置偏好影响仍未验证。

| 方法 | 完整响应 | A原校验合法 | B细诊断合法 | C确定性格式处理后合法 |
| --- | ---: | ---: | ---: | ---: |
| Free | 270 | 179 | 179 | 179 |
| Hybrid | 93 | 71 | 71 | 71 |
| NoCW | 99 | 59 | 59 | 59 |

A/B完全一致。C只允许唯一完整JSON code fence解包，没有历史样本被挽救。重复键、NaN、截断、多对象、正文夹杂等歧义不猜补。不能把mock局部修复的成功混入C，也不能声称B提高合法率。

153个非法响应中，145个（94.77%）可作结构上的局部定位，8个（5.23%）需完整重规划；**145个仍然需要新的科学回答与意图审查，不是已经修好**。462个完整JSON中460个具有可靠choice结构，另外2个不能构建确定实验批次。是否能在新LLM回答中真正保留设计、减少请求，离线历史无法回答。微秒/毫秒计时仅是本机单进程计算；读取文件、构造上下文和加载AST另计，B−A的小负值属于计时噪声，不宣称加诊断反而加速。细项见[BENCHMARK_NOTES.md](BENCHMARK_NOTES.md)及[离线结果](offline_benchmark_results.json)。

## 5. Numerical Critic：只准备Level 2

独立 `numerical_critic.py` 接收冻结有序L/U、同checkpoint预测、既有梯度表示、合法32点计划和选前反馈；检查来源凭据一致性、维度、时间与ID。输出覆盖及增量、冗余关系、严格单轴条件对照、同分子设计、历史反馈邻域与可复核项，不提供任意加权总分，不替换选点。

11项mock测试通过；29项几何指标与既有Free机制脚本逐项对齐。分位交叉和负width作为模型诊断保留，不把已有预测质量问题误作非法计划。小型mock（8L/40U、32点、5维）单次约2ms，仅说明接口可运行，不外推真实全池速度。

低CW/raw距离可能与严格loading对照同时出现。已有Free/Hybrid审计支持保留这种科学局部设计，未证明低覆盖点无价值，也未证明化学先验一定优于当前表示。哈希只能检查所供凭据一致性，不能自证数据来源真实；接口没有接入生产读取器。详见[NUMERICAL_CRITIC_INTERFACE.md](NUMERICAL_CRITIC_INTERFACE.md)。

## 6. 科研价值与下一步裁决

**当前问题是否足够系统、值得研究？** 对Level 1，答案是肯定的：310批中114轮需要纠错，增加152个完整模型答案，并存在10个超过原三答案的轮次；不是几次重复ID的轶事。对“科学Agent如何提高闭环学习效率”，这些仍只是系统可靠性证据，不能单靠本审计确立新Agent的研究收益。

**哪些属于工程修复？** 连接与限流、超时/流恢复、JSON/schema、数量、候选ID定位、唯一性、L/U归属、typed证据集合与冻结绑定，都应由确定性宿主可靠防止非法执行。现有validator已挡住这些错误；不足在于fail-fast反馈粗、整批再生成和有限纠错额度的运行代价。安全短索引、一次列全错误和保留合法slot应先作为工程基线。实际从坏哈希猜原意、把证据改成哪条、补选哪个实验，则不能靠工程替LLM作科学决定。

**哪些值得上升为科学Agent研究？** 在合法性已保证的前提下，如何保留可验证条件对照、区分观测与预测依据、根据反证修改hypothesis，以及如何在数值覆盖与局部化学设计冲突时改进决策，才是Level 2问题。必须用结构化主张与真实选点核验，不能按同分子集中或低距离预先判错。

**优先级：先候选定位与证据约束的局部纠错，再做同状态数值反馈修正评价。** 不优先开发更复杂Agent、loading cap或固定CW16配额。未来首先检验短索引/细诊断/局部patch是否在同冻结状态减少非法答案与整批漂移；通过后再比较合法原方案与Numerical Critic反馈修订。此建议不构成执行授权。

| 层次 | 本次证据 | 不能提前声称 |
| --- | --- | --- |
| Level 1 系统可靠性 | 历史错误、代价、诊断与mock不变式已验证 | 新LLM真实局部修复成功率已经提高 |
| Level 2 科学决策质量 | 既有行为线索、独立接口与静态指标对齐 | 数值低覆盖等于低科学价值；Critic已优化真实计划 |
| Level 3 闭环学习效率 | 本次没有新训练对照 | AULC、标签效率或泛化已经改善 |

历史失败数量足够支持工程可靠性改进；完整结构坏样本仅少量，且没有新patch响应、随机化同状态选择或训练对照，不足以验证复杂框架、局部修复语义成功率或学习收益。复现与自检见[README.md](README.md)、[PREFLIGHT_REPORT.md](PREFLIGHT_REPORT.md)，实现边界见[DESIGN.md](DESIGN.md)与[PROTOCOL.md](PROTOCOL.md)。
