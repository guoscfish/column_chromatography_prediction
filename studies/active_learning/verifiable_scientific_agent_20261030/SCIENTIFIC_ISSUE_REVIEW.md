# 科学行为与解释的复核边界

本节继承并明确区分既有机制证据，不把历史 validation 曲线或数值集中度用于本次修复阈值。这里只支持“哪些值得复核”，不判定学习价值。

## 行为不是硬错误

既有五 seed Free / LCMD 机制审计发现：Free 每批不同分子平均23.06，对照LCMD为29.22；严格新上样量条件补全比例34.65%对6.65%。Free的冻结raw梯度覆盖改善较小，却存在清晰loading局部对照。因此“同分子集中”与“有科学对照目的”可同时成立，不能写成重复ID失败，也不能按低距离自动替换。

既有两 seed Hybrid 审计的宽loading口径与严格单轴口径方向不同；Hybrid内部LLM16没有稳定减少loading。它直接限制了“先加loading cap即可修复决策”的论证。已有反馈病例可证明LLM会引用已揭示结果调整命题，但尚不能证明该变化导致AULC改善。

来源：[Free / LCMD机制报告](../free_lcmd_mechanism_diagnostics_20261029/REPORT.md)、[Hybrid审计](../hybrid_loading_cap_audit_20261029/REPORT.md)。这些数字只是各原报告窗口的背景，不与本次新增可靠性分母混合。

## 合法选择仍可有不可追溯解释

`scientific_issue_review.py` 复用既有两 seed、前15轮 Free32 / HybridLLM16 的 `reason_id_reference_audit.csv`，不读取新的标签。原表共1835个20-hex引用出现位置，其中1808属选前L、9属同批LLM、10属其他合法候选、4属pending CW、4未知。这里的分母是引用出现位置；不是1835个独立实验或批次。

对4个未知引用逐条阅读原文：

| 方法 / seed / round | 判断 | 含义 |
| --- | --- | --- |
| Hybrid / 157 / 9 | 明确排除该未知ID | 不构成肯定引用实测证据 |
| Free / 157 / 5 | measured与unavailable并存，随后改引其他观测 | 语义含混，保留人工复核 |
| Hybrid / 6101 / 9 | 明确写该未知ID测得8.34/45.06 | 在当前轨迹catalog中无法追溯；不能用其他数据补出依据 |
| Hybrid / 6101 / 12 | 称未知ID为para-bromoanisole anchor | anchor关系不可追溯；不自动猜成近似合法ID |

这说明“引用了未知ID”不能一律算幻觉，也说明通过旧validator不等于每句科学解释均可验证。结构化证据列表的集合归属是工程可检查问题；该证据是否支持命题、条件是否真正匹配，则是科学语义问题。本次只给出有来源的病例，不估计整个Agent的语义错误率。

## 下一步需要的证据

1. 合法方案内是否存在“声称严格对照而实际多轴变化”的系统模式，需逐条结构化声明和精确条件核验，不能只做loading关键词统计。
2. 反馈是否改变下一轮假设，需同一轨迹的命题、支持/反证关系及实际选择；关键词或hypothesis ID变更不是充分证据。
3. 数值低覆盖与科学对照的冲突，需同冻结状态的原方案、诊断、修订方案和以后同标签预算训练。现有跨轮相关、历史不同版本/路径不能替代该对照。

本次不启动这些实验；保留独立Numerical Critic接口供未来使用。
