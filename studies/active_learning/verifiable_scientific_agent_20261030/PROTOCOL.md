# 离线审计与原型协议

研究日期：2026-10-30，Asia/Shanghai。范围是 4g QGeoGNN-V2 Row-split 的已有 Free、Hybrid、NoCW 科学选样轨迹。本次只验证 Level 1，并准备 Level 2 的诊断接口。

## 数据边界

1. Free 使用五 seed 到 L1485 的权威逐轮来源；Hybrid 使用两 seed 权威冻结轨迹，逐 seed 报告实际可用末端；NoCW 以本地一次固定清单中的已冻结批次为准。
2. 依据 `batch_freeze`、`selection`、`attempt`、`turn`、`rejected`、`contract`、`input`、`catalog` 的完成与哈希链判定。候选元数据只取结构、条件、预测及 ID；观测证据只取选前 L_t。已有 feedback 只属于已揭示历史，不能混用其他 seed / method 的观测。
3. 正在写入的轮次、started 标记和不完整流不当作完整答案。截取之后的新 NoCW 冻结批次不追加到主结果。当前进行中轮次即使已有几次完成错误，也不能与已成功冻结批次混作同一最终合法率分母。
4. 不解析包含未测量真值的 prediction CSV，不读原始全量标签表或 test 真值，不重新训练或重提梯度。此处未读取 test 不能消除旧实验已曝光 test 的历史局限。
5. 所有输出写入本研究目录；生产代码、历史文件、NoCW worker / 锁 / 纠错上限 / 协议均保持原状。不运行历史控制器的 activate、resume、validate 或训练入口，避免导入产生副作用。

## 统计单位与成本

- 批次单位：唯一 `(method, seed, round)`，继承副本不重复计数。Hybrid 的科学 LLM 输出数为 16，与 pending CW16 合为 32；其 LLM16 首次合法率不能伪称为自由 LLM32 的结果。
- 首次输出合法率：首个完整决策答案通过该轮原约束的批次数 / 有可分析首个完整决策答案的批次数。没有完整首答案的历史例外不猜填。
- 最终合法率：被纳入的冻结批次中，经冻结证据核验的最终合法批次比例。这是已完成批次条件统计，不能外推为所有启动轮次的无条件成功率。
- 纠错：一次完整答案被 validator 拒绝后，要求新完整答案。网络失败后的同 turn 重试另计。若生成了 query，应按原协议区别 query 与最终 selection，不算作一次非法决策。
- 失败类别以互斥主类别汇总，细粒度多标签单列。单个答案同时有重复与池外时不得按两个模型请求计费。
- NoCW 采用五 seed runner 实际覆盖的 `validate_plan()`（保留 Free prose-ID规则），不误用 `nocw_inputs.py` 中未运行 paired 协议的额外 prose 禁令。
- 请求、耗时、token 使用冻结记录实际值。耗时求和是记录的请求生成时间，不含未记录的退避、人工等待和训练；缺值覆盖率同时报告。没有冻结 tariff 或实际账单时，费用为 NA。
- 每个合法批次的记录成本包含该轮已保存失败与纠错请求；缺档意味着下界或未知，不能声称完整账单。首次合法判断、served model 与 configured model 分列；混合版本和历史例外不强行归入一个版本。
- 输入字节数 / 候选数 / L 数与失败的关系为描述性关联；轮次、模型、seed、记忆长度、纠错后的更长上下文互相混杂，不据此推断长上下文导致失败，也不将轮次作为独立重复做显著性检验。

## 纠错轨迹

每个纠错轮比较第一次完整且结构可靠的提案与最终接受方案，报告合法唯一候选数、交集、删除、增加与完整批次再生成。不能解析的首提案标不可分析，不能用正则从自由文本拼一个批次。分子集中与严格条件对照来自实际 ID 的元数据；理由文本 / 假设变化只支持审查线索，不能自动判定科学意图完全保留。几何缺档保留 NA。

## A / B / C 离线评价

| 方案 | 含义 | 可作结论 |
| --- | --- | --- |
| A | 原完整候选池输出，经对应历史原 validator | 原规则的合法性基线 |
| B | 同一输出、同一原合法性判定，加细粒度诊断 | 诊断覆盖与定位能力；合法率应与 A 相同 |
| C | 仅唯一、完整、无语义变化的确定性格式处理，再经 A | 可证明的格式处理收益；不能替换选择或改科学证据 |

局部修复请求与响应只用 mock。任何需要增删真实实验、修改引用含义或修改假设的操作，都需要新的 LLM 科学决策；本次不实际发送。mock 的成功不计入历史 C 的合法率，也不作为真实节省请求数。

## 可解释性门槛

- Level 1：输出合法性、失效率、请求与等待代价；本次可验证。
- Level 2：合法计划的信息价值、科学对照与数值诊断；本次只准备接口及静态线索。
- Level 3：相同标签预算下的学习效率；必须未来采用同状态、同版本、相同标签预算的严格训练对照，本次没有证据宣称改善。

离线原型和审计完成后停止。报告中的下一步是条件性建议，不授权新的闭环、LLM、标签揭示或训练。
