# 概率资格门槛未全部通过：独立诊断

本次未通过五 seed 全覆盖资格，既有真实的高斯边际形状失配，也有 333 个 OOF 样本下的硬阈值敏感性。证据不支持将其概括为“模型区间欠覆盖”“数值 GP 失败”或“EPIG 无效”。本诊断不改变冻结门槛、不增加模型拟合，也不读取 U、validation 或 test 的标签。

数据范围是原始 L333 的合法标签与已保存 OOF 预测。每个 OOF 预测来自仅使用其余 222 行拟合的模型；333 行合起来构成一次三折 OOF 评估。这不等同于已经验证实际全 L333 拟合后验的校准。20 个 seed×family 状态完成 60 次辅助拟合；本诊断新增拟合为 0。

## 1. 资格决策实际由什么触发

17/20 个模型状态未通过，原因全部是至少一个端点的名义 80% 区间覆盖率超过冻结上限 0.90。没有状态因为 95% 覆盖、标准化残差 RMS、正定性或平均联合 NLL 退化而失败。157 和 12203 的 Matérn GP、2357 的 coupled BLR 通过；887 和 6101 没有通过的候选族，因此全五 seed 正式执行门槛未满足。

以下为十个 seed×endpoint 值的等权描述均值；这些重复且重叠的 L333 数据不能当作十个独立推断单位。

| 概率模型 | 80% 覆盖 | 95% 覆盖 | 标准化残差 RMS | 标准化残差超额峰度 |
| --- | ---: | ---: | ---: | ---: |
| RBF GP | 0.90150 | 0.94625 | 1.03734 | 13.146 |
| Matérn-3/2 GP | 0.89820 | 0.94535 | 1.04624 | 12.891 |
| independent BLR | 0.91682 | 0.95135 | 1.02625 | 13.347 |
| coupled BLR | 0.90090 | 0.94204 | 1.17921 | 13.299 |

“RMS 接近 1、95% 覆盖接近 95%”不能排除中部区间严重过覆盖。50% 区间的实际覆盖也明显偏高；这一项虽保留在原始指标中，但不是当前冻结的硬 gate。

## 2. 尖中心与重尾同时存在

令 z=(y−预测均值)/预测标准差。对全部 40 个 seed×family×endpoint 状态：

- |z| 的中位数为 0.228–0.507，标准正态应为 0.6745。
- |z| 的 80% 分位为 0.673–0.979，标准正态应为 1.2816。
- 超额峰度为 9.57–16.60，标准正态为 0；每个状态仅最大的 4 行，即 ceil(333×1%)，贡献 32.0%–41.7% 的标准化残差平方和。
- 最大 |z| 为 5.80–8.49；|z|>3 的行占 1.80%–4.20%。这些数值是诊断，不能据此给这些合法观测贴上“错误标签”或删除。

因此，少数较大误差维持了接近 1 的全局二阶矩，主体误差则比相应高斯分布更集中。高斯同方差噪声的 MLE 主要平衡平方误差，不能同时保证所有分位区间校准。这与“所有区间都简单宽了一倍”的解释不同。

作为事后形状诊断，若只想使中心 80% 经验区间匹配，宽度乘数约为 q80(|z|)/1.2816；族均值为 GP 约 0.602、independent BLR 0.587、coupled BLR 0.672。但 95% 对应乘数的族均值为 1.028、1.043、0.947、1.091。一个统一缩放无法同时修复这两处 CDF 形状。本研究没有应用这些事后乘数，也没有据此重算资格或 acquisition。

## 3. 硬上限 0.90 的边界也确实敏感

333 行时，0.90×333=299.7，因此硬门槛容许的最大成功覆盖数为 299。300/333=0.900901 已失败。12203 的 RBF V1 正好属于这一情形：一行的区间归属改变即可越过门槛。

以 Matérn V1 为例：

| seed | 覆盖数/333 | 覆盖率 | 达到上限需减少的覆盖行数 | 描述性 Wilson 95% 区间 |
| --- | ---: | ---: | ---: | --- |
| 157 | 296 | 0.888889 | 0 | [0.85060, 0.91831] |
| 887 | 303 | 0.909910 | 4 | [0.87430, 0.93617] |
| 2357 | 303 | 0.909910 | 4 | [0.87430, 0.93617] |
| 6101 | 304 | 0.912913 | 5 | [0.87773, 0.93868] |
| 12203 | 299 | 0.897898 | 0 | [0.86071, 0.92601] |

40 个端点状态中，26 个因覆盖率 >0.90 触及上限，其中 24 个的 Wilson 区间仍包含 0.90。按 L333 中分子簇进行的 2,000 次固定预测 bootstrap 也得到 24/26 个包含 0.90。每个 seed 的 L333 约含 165–169 个分子簇，复用训练折还会引入额外依赖；上述区间只能作有限样本敏感性描述，不是独立二项实验的精确置信保证，bootstrap 也未重新拟合模型。

另一方面，全部 40 个端点状态的这两类描述区间下界均高于名义 0.80。因而“0.90 附近的通过/失败判别不稳定”与“名义 80% 实际过覆盖”可以同时成立。不能仅因失败接近门槛就断言模型已校准，也不能仅因点估计略超过 0.90 就断言其联合后验完全不可用。

本研究遵守冻结 gate；没有把上限事后改为 0.92 或 0.95。若下一阶段使用包含采样不确定性的等价界限，必须预先注册，并在独立或明确划分的确认数据上验证，不能用本次结果反向定义“合格”。

## 4. 条件校准仍不充分

按已保存预测标准差分为四组后，名义 80% 覆盖为 0.786–0.976，标准化残差 RMS 为 0.388–1.665。预测标准差与绝对误差的 Spearman 相关为 −0.092 至 0.156，族平均接近 0。这表明当前预测标准差没有稳定地把较难预测行排到更高不确定性位置；仅看全局覆盖会掩盖条件差异。该相关不构成协方差无效的充分证明，且混合不同训练折的噪声估计也可能影响它。

另外保存了按预测均值分组的条件诊断，避免用未来真实标签给样本分层。所有分组只使用 L333 OOF 预测。没有按当前 U 的真实值、oracle 信息量或最终验证表现挑选模型。

## 5. 数值优化、核、噪声和 PCA 状态

60 次训练的所有优化器均报告收敛，全部噪声参数都没有命中预设上下界，完整 OOF 预测协方差的最小特征值均为正。GP 标准化空间噪声方差范围为 0.00509–0.78130，核尺度为 1.766–12.032，因此本次并非所有模型被强迫使用固定单位噪声或同一个退化长度尺度。

16 维 PCA 保留训练侧标准化输入方差的 98.87%–99.22%。这一数值排除了严重丢失大部分总输入方差的情况，但不能证明低方差且与标签相关的条件方向都已保留。当前 OOF 文件未保存逐方向响应控制，不能从保留方差比例推出上样体积学习能力合格，更不能把辅助模型校准失败归因于 QGeoGNN 的体积响应瓶颈。QGeoGNN 尚未在此研究新增拟合，其可学习能力是另一个研究因素。

GP 假设独立端点、单一各向同性核和每端点同方差噪声；BLR 使用线性均值、共享空间协方差，coupled 版本的 B 为训练中心化响应的收缩协方差。它们都使用 empirical Bayes 点估计，没有积分核超参数或均值估计的不确定性。不同假设仍产生相似尖中心/重尾，支持“该标签/特征关系下同方差高斯边际形状不足”的解释；数据、均值函数、条件噪声和尾部误差各自的因果贡献尚不可识别。

## 6. 联合 NLL 不能被误读成跨样本相关已经证实

完整联合 NLL 与删除跨样本相关后的逐行 block NLL 的平均差值，RBF GP 为 +0.00113、Matérn GP 为 +0.00986、independent BLR 为 −0.00497、coupled BLR 为 −0.00583 nat/标量。差异小，未给出跨样本相关强烈可靠或完全失效的证据；单折差值范围为 −0.03267 至 +0.15450，状态平均可能掩盖折间不稳定。

coupled BLR 的完整联合 NLL 相对逐标量独立 NLL 看似改善约 0.336 nat/标量，其中约 0.330 来自同一行 V1/V2 的相关性，而跨行部分约 0.00583。不得把这主要由端点耦合带来的改善写成“跨样本 EPIG 所需的相关结构已充分验证”。其先验与噪声共享 B，完整双输出 mutual information 可经可逆白化消去 B；该路线提供真实的输出依赖，却不能据此宣称已展示超出独立输出的全新 batch EPIG 决策价值。

## 7. 能支持的结论与下一步边界

当前证据支持：数学上可计算 Gaussian EPIG；已注册概率族存在具体的边际分布形状问题；五 seed 全覆盖的冻结资格条件尚未满足。它不支持：EPIG acquisition objective 比 IVR 差、batch EPIG 无效、QGeoGNN 无法利用新实验，或长期 row-level 学习性能不改善。这里没有任何新的 QGeoGNN 学习曲线来检验这些命题。

最有证据支持的暂时归类是 **A（特定概率模型的边际校准不足）与 F（正式学习性能证据不足）并存**。gate 边界敏感性是额外限制，不能单独充当 A 的机制证据。B、C、D、E 都仍需其各自的冻结对照才能区分。

合理后续应先预注册一个有界、独立的概率校准确认阶段，考虑条件噪声及非高斯尾部。若改为 Student-t、混合模型或非高斯联合分布，Gaussian EPIG 的闭式公式不再自动适用，必须另行验证对应互信息估计；不能只改变边际样本再假装具有跨样本依赖。当前结果也不授权无限增加核、seed 或噪声拟合直到通过。严格 gate 不改动的情况下，正式五 seed 结果应继续标记为未完成，而不是报告负面的 Go/No-Go。

## 可复现入口与数值

```bash
MPLCONFIGDIR=/tmp/epig_analysis_matplotlib KMP_DUPLICATE_LIB_OK=TRUE OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 conda run --no-capture-output -n fish python studies/active_learning/epig_prediction_oriented_20261117/analysis/qualification_failure_analysis.py
```

输出 `qualification/failure_analysis/`：

- `residual_shape.csv`：40 个端点状态的残差分布、经验分位、门槛距离及不确定性区间。
- `conditional_calibration.csv`：按预测标准差及预测均值四分位的条件指标。
- `fitted_parameters.csv`：所有 fold 的核、噪声、PCA 与收敛状态。
- `joint_dependence.csv`：三种联合/独立 NLL 分解及跨样本部分。
- `input_hashes.csv`：全部诊断输入的 SHA256。
- `summary.json`：数值范围与零新增标签访问/拟合声明。
- `coverage_curves.csv` 与 `probability_calibration_diagnosis.png`：经验校准曲线和四个尾部观测的误差占比；阴影为状态范围，不是置信区间。

本分析脚本位于单独的 `analysis/`；不修改已冻结模型、资格阈值、OOF 文件或正式选点实现。
