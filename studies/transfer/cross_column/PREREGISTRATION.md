# Cross-column transfer validation preregistration

We test whether transfer across column specifications is primarily a low-dimensional calibration problem or requires condition-/representation-dependent adaptation. Targets use verified times when available, no target volume threshold, fixed source-only preprocessing, five fixed seeds, row and target-compound-disjoint protocols, and nested low-label budgets. Simple models fit gradient-train labels only; Ridge alpha selection is nested GroupKFold and refits affine inside each fold; neural checkpoints use validation only; test labels are read only after all fits freeze. The mass-ratio model is descriptive only. Target-compound holdout is not called source-unseen OOD. No active acquisition, architecture search, full fine-tuning, or test tuning is permitted.
