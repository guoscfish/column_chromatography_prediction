# Research direction

Historical Legacy → condition-complete correction → function-preserving pruning → standalone QGeoGNN-V2 → current predictor.

The standalone QGeoGNN-V2 is `4G_POINT_PREDICTOR_QUALIFIED_FOR_TRANSFER_STUDIES`. Predictor architecture is no longer the default research target. Ordinary transfer proceeds independently of UQ qualification; active transfer requires independent transfer validation and an adequate uncertainty contract.

The current sequence is reliable predictor → ordinary small-label 4g→8g transfer → independent validation, with UQ qualification in parallel → active transfer when both are adequate.

The completed 4g qualification and frozen target baseline answer different estimands. Six source runs characterize row interpolation and novel-compound generalization. The transfer study holds one preregistered source checkpoint fixed and compares five adaptation families across five target row partitions and four nested label budgets. Source-seed variability and independent compound/column validation remain outside that transfer estimand.

Historical E2/A1a and T1/T1b/G0/S1 outcomes remain measured evidence from their original predictors and designs. They are not corrected-predictor confirmation. No active sampling, architecture repair, head benchmark or adapter sweep was run in this cycle.
