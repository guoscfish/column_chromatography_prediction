# 4G LLM Dual Expert Active Learning V1

The original September 27 implementation ended at round-0 selection. On October 10, the user requested a complete implementation and two real acquisition/retraining cycles. The new implementation uses an isolated revision under the existing study; the original draft and protocol remain historical records.

`free_llm32_dual_expert_v1` tests independent chemistry/chromatography and machine-learning/active-learning advice followed by a free Scientific Planner. Relative to `free_llm32_scientist_v2`, the reasoning architecture is the intended strategy variable. Row split, L333 initialization, candidate pool, QGeoGNN prediction schema, batch size, training configuration and checkpoint rule use the current Scientist pipeline.

Each role receives all legal current candidates and all observed records in the same lossless full-catalog encoding used by free/llm+cw. There is no retrieval or shortlist. The two scientists have independent transcripts and catalog instances and cannot see the current other scientist's memo. The planner receives both completed memos and the full packet, explains agreements/disagreements and owns the final 32-ID decision. There is no fixed CW or expert allocation, rank aggregation or hidden reranking.

Every role also receives trajectory-local historical selected plans, hypotheses, rationale, prior scientist memos, measured outcomes and premeasurement errors. The latest 32 outcomes and largest historical error records are explicit; all older measured records remain in the complete observed table. Seed/method checks reject foreign history. Expert memos and planner decisions remain bound to their own packet hashes.

The executable lifecycle reuses the extracted parameterized `scientist_lifecycle` and the original Scientist prediction and training components. The frozen legacy `scientist_study.py` stays unchanged so concurrent free/llm+cw runs remain valid. All 32 IDs and premeasurement predictions freeze before label reveal. Each batch is revealed, its full plan and role memos attached to measured feedback, and QGeoGNN retrained from the original initialization with the same optimizer and validation selection rule. Round t+1 reads the completed round t model and the verified measured feedback. Replay audits consume saved role answers and make no new calls. Transport, bounded retries, response completion/model/tool checks and provider-key handling use the current Scientist transport.

The default run is seed 157, two cycles, 333→365→397 labels. `--rounds` can explicitly request up to six cycles. Each role has up to three final-answer attempts, including bounded format corrections. Validation comparison reads completed fit audits at equal budgets for the dual expert and historical free, llm+cw, CW32 and Random32 methods. This report does not reveal test truth or pass validation performance to LLM selectors.

The architecture does not isolate the causal effect of chemistry knowledge: prompt framing, role decomposition, extra calls and planner context can all affect results. One seed and two cycles provide exploratory development evidence only.
